---
title: "A small backup routine"
---

My working folder and its backup should not depend on the same disk. Once a month I restore a small project into a separate directory and open the files, rather than trusting a green status icon.

Synchronization is convenient, but it can also copy an accidental deletion. I keep dated snapshots and one disconnected copy. The restore note records what was recovered and which application could open it. A backup that has never been restored is still an assumption.
