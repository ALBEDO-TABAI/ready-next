# Character-Costume Forge — 人物设定与服道化锻造器

## 0. 定位与边界

这个 skill 是**角色视觉翻译器**：把剧本里的角色（叙事层）翻译成 AI 图像/视频模型能精确执行的"视觉身份 + 服道化"（生成层）。

它在流水线里的位置：
```
[脚本 + 分镜]  ← 上游（已存在，本 skill 的输入）
      ↓
[本 skill] 人是谁 · 长什么样 · 穿什么 · 怎么演 → 角色设定 + 服道化 + AI 提示词
      ↓
[video-prompt-forge] 运镜 · 景别 · 节奏（把本 skill 产出的角色当作"主体"输入）
```

**只做**：在已有脚本 / 分镜下，为角色生成"视觉身份 + 服道化"的 AI 生成提示词包（图像 + 视频）。
**不做**：写剧本 / 分镜（上游）；运镜与节奏设计（下游交 `video-prompt-forge`）；实拍剧组的采买执行清单（本 skill 面向 AI 生成，不是真人剧组的物料手册）。

---

## 1. 核心理念

四条第一性原则，贯穿全流程：

1. **Character Through Appearance（外貌先叙事）**：人物外表必须在观众意识到之前，先告诉观众"这个人是谁"。服化道不是装饰，是**视觉信息编码**——身份 / 阶层 / 职业 / 性格 / 心理状态 / 成长轨迹，都要能从外观读出。

2. **Character Triangle 一致性（总法则）**：一个可信角色由 **外在（别人看到的）× 内在（欲望/恐惧/创伤）× 行为（动作/表情）** 三维决定，且三者必须一致。冷酷杀手＝锋利五官（外）+ 恐惧亲密（内）+ 回避眼神（行）。**任何一维与另外两维打架，角色就散了**——这是本 skill 最高优先级的校验。

3. **叙事驱动，非审美堆砌**：每个视觉决策都要能回答 **Three Questions——为什么是这个？为什么这个时候？为什么这个人？** 答不上来的元素删掉。

4. **Identity Lock（AI 一致性）**：AI 生成的核心难题是角色跨调用漂移。把身份冻结成可复用的 Character Sheet，是让多张图 / 多个镜头"是同一个人"的前提。

> 全流程的查表语法都在 `references/mapping-dictionary.md`。每一步指定读哪一节，逐项查表、逐项挂视觉依据。
> 一个可参照的完整示例在 `references/worked-example.md`——不确定输出到什么颗粒度时读它。

## 2. 执行流程

### STEP 0 — 信息门槛检查（先做，不满足就停下来问）

**这是本 skill 的硬性纪律**：信息不足时脑补出来的角色，大概率与用户脑中的剧本错位，会浪费整份产出。所以先检查、缺就问、问一次、然后动手。

**阻断级信息（缺任一项 → 停下来问，不要开始设计）：**

| 项 | 为什么阻断 |
|---|---|
| **剧本 / 分镜内容**（或其要点：角色是谁、故事前提、关键场景/情节点） | 没有故事就没有角色，Character Triangle 的"内在"无从谈起 |
| **要设计哪些角色**（全部？只主角？主要几人？） | 决定工作量与对比设计范围 |
| **真实性锚点**：题材 + 年代 + 地域 + 写实度（当代？年代戏？哪个年代？奇幻？写实 vs 风格化？） | "当代东京上班族" vs "1920 上海" vs "赛博朋克"的服道化天差地别，猜错整份报废（见词典 §20） |

**可推断信息（缺就用默认值，并在产出里注明假设，不要为这些反复追问）：**

| 项 | 默认 |
|---|---|
| 目标生成工具 | 通用结构化 prompt + 中英双语（多数模型对英文响应更好）；若用户指定 Midjourney/gpt-image/Kling/可灵/Sora 则按其语法微调 |
| 每个角色的情绪基调 | 从剧本意象与语气推断（如"雨"偏忧郁/孤独，主动完成这层文化符号学判断） |
| 变体维度 | 默认按"整体美学方向"变（见 STEP 7） |
| 变体数量 | 默认 2 种；用户可要 1 或 3；剧本极简单可 1，探索性强可 3 |

**门槛未过时的处理**：合并成**一次**聚焦提问（不要挤牙膏式一条条问），模板：

```
在动手前，有几处信息缺失会直接影响设计方向，先和你确认：
1.〔剧本/分镜〕能贴一下剧本或分镜要点吗（角色是谁、故事前提、几个关键场景）？
2.〔角色范围〕这次要设计哪几个角色？
3.〔真实性锚点〕题材是当代 / 年代戏（哪个年代）/ 奇幻？追求写实还是风格化？有没有年代、地域的硬设定？
（可选）目标生成工具？变体想变的维度（整体风格 / 造型强度 / 生成友好度）？要几种方案？有没有品牌、禁止元素、演员等硬约束？
```
问完停住，等用户补齐再进 STEP 1。**门槛过了就直接往下走，不要额外追问。**

### STEP 1 — 人物定位 + Character Triangle（每个角色一次）

从剧本为每个待设计角色抽出：

1. **一句话定位**（Character Bible 的种子）：如"表面优雅、实则疯狂爱钱的贵妇"。
2. **3–5 个核心人格关键词**：如 奢华 / 虚伪 / 控制。控制在 3–5 个，多了视觉会跑偏。
3. **身份档案**：身份 · 阶层 · 职业 · 年龄 · 心理状态。注意**当下阶层 vs 出身**的落差往往是设计金矿（如"精英律师，但童年贫困"——身上会留有两套痕迹）。
4. **Character Triangle 三维**：
   - 外在 Appearance：年龄 / 身高 / 体型 / 长相
   - 内在 Psychology：欲望 / 恐惧 / 创伤 / 信念
   - 行为 Behavior：动作 / 语言 / 表情
5. **角色弧线**：若剧本里这个角色会变化，记下 `初始状态 → 变化事件 → 心理转折 → 最终状态`（供 STEP 6 的服装/发型/表情弧线用）。

**本步校验**：写下三维后，检查它们是否互相印证。若"内在＝恐惧亲密"却给了"开放热情的行为"，说明还没想清楚，回去改，别带着矛盾往下走。

---

### STEP 2 — 视觉关键词映射（心理 → 画面）

读 `references/mapping-dictionary.md` **§1（人格→视觉）**。把 STEP 1 的每个人格关键词逐个翻译成视觉倾向（冷色 / 锐角 / 柔软材质 / 结构化剪裁……）。这层是后面所有具体设计的总纲。

若人格关键词彼此矛盾（温柔+危险），保留矛盾但**定主次**——复杂来自受控的矛盾，不是各占一半（见 §1 说明与 STEP 8 的"生理矛盾"红线）。

---

### STEP 3 — 人物本体设计（身体 / 脸 / 毛发）

这一步设计"人本身"，独立于服装。读词典 **§2–§8**，逐层定：

- **轮廓 Silhouette（§3）**：先定肩 / 腰 / 下摆 / 头四部位与整体轮廓形。**黑影可辨**是硬标准。
- **形状语言（§2）**：主形一种（圆/方/三角），可加第二形做复杂度。
- **体型 + 头身比（§4、§5）**：写实锁 7–8 头身，风格化/英雄可 8–9。**把目标头身比写进 prompt**，否则模型默认时装 9 头身。
- **五官语言（§6）**：眼 / 眉 / 鼻 / 下巴 / 眼距逐项定，每项挂它服务的人格。
- **面部不对称（§6b）**：加轻微不对称提升真实感，但克制以免模型渲染成畸变。
- **年龄（§7）**：结构 + 质感 + 动作三者齐动，不是只加皱纹。
- **毛发（§8）**：长短 / 整洁 / 发际线 / 状态，逐项挂人格。

---

### STEP 4 — 表演与动作设计（视频必做，图像也影响姿态）

角色设计里最常被跳过、却决定 AI 视频成败的一层。AI 视频当前最大短板不是"人不好看"，而是**没有稳定的动作逻辑与表演节奏**。读词典 **§9–§14**：

- **动作签名 + 重心（§11）**：定这个角色独特的身体习惯（走路 / 停顿 / 手势）与重心（前倾攻击 / 后仰疏离 / 低重心稳定）。
- **拉班主 Effort（§12）**：选 1 种主 Effort（Press / Punch / Flick…）+ Flow 质感，作为跨镜头的动作基调。
- **默认表情 + 表情库（§9）**：用 FACS 描述而非情绪名。至少备：默认 / 开心 / 愤怒 / 悲伤 / 惊讶 / 思考 / 嘲讽。注意真笑(AU6+AU12) vs 假笑的区分。
- **视线 + 镜头行为（§13）**：定"面对镜头 / 压力下 / 开心时"的默认视线。
- **静止的力量（§14）**：为关键情绪镜头保留"少动 + 眼神变化"，张力更强，也降低 AI 一致性负担。
- **微表情（§10）**：只在分镜关键帧标注，不进静态图 prompt。

---

### STEP 5 — 服道化设计（服装 / 色彩 / 材质 / 磨损 / 道具 / 化妆）

给"人"穿上叙事。读词典 **§15–§19**，每件都过 **Three Questions（为什么是这个 / 这个时候 / 这个人）**：

- **服装廓形 + 剪裁**：强化 STEP 3 的轮廓与形状语言。宫廷剧 / 群像用 **Costume Hierarchy**（高位角色明亮 / 大面积 / 贵重材质，让视觉自动排序）。
- **色彩资产（§15）**：主色 60% / 辅助 30% / 强调 10%。**必须用描述性色彩语言**（琉璃青 / 暖驼 / 雾霭灰），不写扁平色名。
- **材质叙事（§16）**：关键材质挂心理含义（丝绸＝权力 / 皮革＝危险 / 旧布＝经历）。
- **磨损逻辑（§17）**：不是"做旧"，是"为什么旧、旧在哪"，每处磨损回答一个人生问题。
- **标志道具（§18）**：Hero Prop + 它的来历（谁买的 / 用了多久 / 为什么留着）。
- **化妆心理（§19）**：皮肤状态编码心理（湿润＝健康 / 苍白＝疾病恐惧 / 油光＝压力）；老化＝结构+颜色+质感三变化。

---

### STEP 6 — 变化线（如剧本有弧线）

若 STEP 1 记下了角色弧线，把它落成**可见的服装 / 发型 / 表情演变**（读词典 §8 发型弧线、§15 色彩弧线）：
```
初始状态（服装/发型/主色/默认表情）
   ↓ 变化事件
中段（哪些元素开始松动/改变）
   ↓ 心理转折
最终状态（服装/发型/主色/默认表情）
```
**情绪映射要平衡**：不要只做"堕落→黑"这类单一负向弧线；正向弧线（雾霭灰→清透天青，表达通透/成长）同样要能表达（见词典 §15 纪律）。

---

### STEP 7 — 对比设计 + 变体组合

**先做跨角色对比（多角色时）**：读词典 **§21**。把所有主要角色放一起，用颜色 / 形态 / 材质 / 新旧四轴拉开区分，做**黑影可辨校验**。AI 在多角色场景最容易把两个人揉成一个，这步是硬校验。

**再定变体维度与数量**（满足用户"1–3 种不同组合"的要求）。每个变体＝一份**内在自洽的完整方案**，变体之间沿一条**明确说明的轴**拉开，且彼此有意义地不同（不是换个色）。常用变体轴：

| 轴 | 说明 |
|---|---|
| **A. 整体美学方向**（默认） | 写实纪实 / 电影感风格化 / 象征表现主义 / 特定导演美学（如 Wes Anderson 对称高饱和） |
| B. 造型强度 / 解读 | 同一性格的保守内敛版 vs 大胆外化版 |
| C. 生成友好度档位 | 高一致性简化版（复杂造型 AI 易崩）vs 高表现力复杂版 |
| D. 弧线锚点 | 剧本弧线可有多种解读时的不同走向 |

每个变体末尾注明：**它优化了什么、牺牲了什么、最适合哪些镜头 / 情绪**，方便用户选。

---

### STEP 8 — Identity Lock + AI 提示词 + 分镜映射

**锁定身份**：把每个变体的 Face / Hair / Body / Costume / Color / Prop 六项冻结成 Character Sheet（词典 §22），作为跨调用参考。

**生成提示词**：按词典 §22 的骨架输出，每个变体给：
1. **Character Sheet 提示词**——用于先生成角色定妆 / 三视图参考图，锁死身份。
2. **单张关键画面提示词**——可直接投喂图像模型。
3. **结构化版 + 纯文本版**（部分工具只吃自然语言段落）。
4. **中英双语**（英文对多数模型响应更好）。

**分镜一致性映射（如提供了分镜）**：这是两份源方法论都指向的最高价值层。为镜头序列产出一张表——**什么锁定、什么随剧情变、每个关键镜的表情/姿态/服装状态**：

| 镜号 | 保持锁定 | 随剧情变化 | 该镜表情 / 姿态 / 服装状态 |
|---|---|---|---|
| S01 | 脸/发/体型/主色/剪裁 | — | 默认表情、重心后仰、外套整洁 |
| S07 | 脸/发/体型 | 外套沾灰、发型微乱 | 一帧微表情(压抑)、重心前倾 |
| … | | | |

→ 每个镜的"角色状态"确定后，**接 `video-prompt-forge`** 生成该镜的运镜 / 景别 / 节奏。

对每个变体，按此模板输出（`references/worked-example.md` 有填满的实例）：

════════ 角色：〔角色名〕 ════════

──── 方案 1：〔方案名〕（在变体轴上的定位｜适配说明：优化了X，牺牲了Y，最适合Z镜头/情绪）────

■ 角色一致性锁定表 / Character Identity Lock
  基础：年龄 · 性别 · 身高 · 体型 · 头身比 · 整体轮廓（剪影特征）
  五官：眼 · 眉 · 鼻 · 下巴 · 面部特征（不对称点）

## 4. 质量红线

- **Character Triangle 一致性**：外在 / 内在 / 行为不能自相矛盾。这是第一优先校验，散了就重来。
- **叙事驱动**：每个视觉决策都要能过 Three Questions。答不上"为什么是这个/这时候/这个人"的元素，删。
- **Silhouette 可识别**：单角色黑影要能认出；多角色黑影排一起要能区分（Contrast Design）。做不到就重设计。
- **真实性三层**：年代 + 阶层 + 个人叠加，不穿"年代标准制服"（除非角色本就是被制度同化的符号）。
- **现实信息不脑补**：涉及真实年代 / 品牌 / 技术 / 地域的服化道细节，**联网核实**再写。历史错误摧毁全套可信度。
- **色彩语言**：用描述性色彩（琉璃青 / 暖驼 / 雾霭灰），不写扁平色名（蓝 / 棕 / 灰）。
- **情绪映射平衡**：弧线与描述覆盖正负两向，不把角色一味病理化 / 阴暗化；也给正向弧线（成长 / 通透 / 释怀）留出视觉表达。
- **视频动作逻辑**：面向视频时，角色必须有连续动作逻辑与表演节奏（动作签名 + 主 Effort + 镜头行为），不只是静态外观——这正是 AI 视频当前最大短板。
- **Identity Lock 稳定**：跨 prompt 调用时，锁定的六项不能漂移；变的只有剧情要求变的。
- **信息门槛**：STEP 0 的阻断级信息缺失时先问再做，绝不带着脑补往下走。

## 5. 语言与适用范围

- **语言**：默认跟随用户语言输出说明；提示词部分提供**中英双语**，因为多数主流图像 / 视频模型对英文响应更好。用户指定语言则从之。
- **变体数量**：默认 2；用户可要 1–3。
- **适用**：已有脚本 + 分镜下，为角色生成"视觉身份 + 服道化"的 AI 生成（图像 / 视频）提示词包，含跨调用一致性锁定与分镜级一致性映射。
- **不适用**：写剧本 / 分镜（上游）；运镜 / 节奏 / 景别设计（下游交 `video-prompt-forge`）；真人剧组的物料采买与执行手册（本 skill 面向 AI 生成）。需要更长叙事的角色连续性，按分镜映射拆镜后逐镜生成。
