# Pipeline Integration — 接入 AI 生成管线（Idealanding 实战补充）

> 2026-07-11 由 epicland-x9 案首用后补写。本 skill 的产出如何接进
> 「参考卡驱动的多镜视频生成」管线（storyboard sheet + 一致性卡 → multimodal2video）。

## 1. Character Sheet → 角色卡（卡片化落地）

STEP 8 的 Character Sheet 提示词在本管线里落成**角色一致性卡**（previz card）：

- 版式：横幅 3 格（全身主视角 / 剪影或侧影 / 服装材质细节特写），一图入库
- **双版本制**：干净版（无文字无编号）喂视频模型作参考；注释版（叠标签）供人审——
  文字禁令挡不住模型照抄参考图上的图形元素
- 生成器：走当前最强生图通路（gpt-image-2 系），限流时降级兜底
- 卡与提示词分工：**卡锁"长什么样"，镜头提示词锁"何时做什么"**（Identity Lock 的运行时形态）

## 2. STEP 0 追加门槛项：面部政策档位

AI 视频的人脸是伪影与身份漂移的高发区。开工前与用户对齐**面部政策**（阻断级）：

| 档位 | 含义 | 适用 |
|---|---|---|
| 无人物 | 全片不出人 | 产品/风景片 |
| 点景档 | 人物=大景中的小人影，背影/侧影/远景，面部低可读 | 山水/意境片（服道化承担全部叙事，Silhouette First 的极致场景） |
| 质量制群像 | 中景群像面部允许，逐帧质量人检为闸 | 青春群像/纪实感 |
| 正面出镜 | 面部特写允许 | 表演向内容（一致性成本最高，需 Character Sheet 多角度锁脸） |

档位决定 Character Sheet 的设计重心：点景档可完全省略五官层（§6），把预算全部投给
剪影/廓形/色彩资产；质量制群像重点锁服装与体型，脸交给距离与人检。

## 3. 与门禁系统的对接

- 角色卡生成后走「声明的参考工件」回执（无产品的一致性工件）
- 成片按镜检查服装锁漂移（判例：跑者卡漏写形制→模型产出连帽/换性别——
  **服装锁必须写全且角色卡必须进参考**）
- 点景档出镜镜头：人物剪影可辨性 = 验收项（黑影可辨的运行时校验）
