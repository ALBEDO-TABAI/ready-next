## 1. 人格 → 视觉 映射（心理到画面的总桥）

这是全套方法的第一根桥。所有后续设计（轮廓 / 五官 / 颜色 / 材质 / 动作）都是这一步的展开。

| 人格 / 心理 | 视觉倾向 |
|---|---|
| 孤独 | 冷色、宽肩、身周留空、疏离站姿 |
| 危险 | 锐角、黑红、直线条、低重心前倾 |
| 温柔 | 柔软材质、圆形轮廓、暖色、开放手势 |
| 控制欲 | 结构化剪裁、硬廓形、精确发型、克制动作 |
| 自负 | 挺拔体态、奢华材质、后仰重心、扩张手势 |
| 脆弱 | 细肩、低饱和、松垮或过大衣物、内收姿态 |
| 阅历 / 沧桑 | 旧材质、磨损痕迹、深眼窝、慢动作 |
| 天真 | 大眼、宽眼距、圆脸、明快色、动作幅度大 |
| 阴谋 / 狡猾 | 三角形轮廓、窄眼距、不对称、少眼神交流 |

**用法**：先从剧本抽出 3–5 个人格关键词，逐个查表得到视觉倾向，再在后续步骤里落成具体的轮廓 / 五官 / 颜色 / 动作。若同一角色的人格关键词彼此矛盾（如"温柔"+"危险"），这不是错误——**复杂角色恰恰来自受控的矛盾**（见 SKILL.md 的"生理矛盾"红线），但要有主次，不能各占一半导致读不出人。

## 2. 形状语言（圆 / 方 / 三角）

动画（Disney / Pixar / DreamWorks）与角色设计的成熟共识。人体、脸、服装、领口、发型都可抽象为三种基础形，并互相强化。

| 基础形 | 心理表达 | 典型用途 | 落点（在哪里强化） |
|---|---|---|---|
| **圆形** | 善良、亲近、无害、可靠 | 朋友、孩子、老人、治愈型 | 圆脸、肉感、柔软动作、圆领、卷发 |
| **方形** | 稳定、力量、固执、权威 | 硬汉、守护者、体制人物 | 宽肩、方下巴、稳定姿态、直线剪裁 |
| **三角形** | 危险、野心、聪明、阴谋 | 反派、谋士、锋利型 | 尖脸、窄身、锐利动作、尖领、上挑轮廓 |

**用法**：一个角色主形一种，可用第二种形做点缀制造复杂度（例：外方内圆＝表面强硬、内心柔软的守护者）。多角色同场时，用不同主形拉开区分（见第 21 节）。

## 3. 轮廓语言（Silhouette）

角色设计第一原则：**变成纯黑影还能不能认出是谁**。设计初期先不管面料 / 花纹 / 饰品，只解决外轮廓。

四个决定性部位：

| 部位 | 承载信息 |
|---|---|
| 肩 | 力量 / 权威（宽＝统治，窄＝脆弱） |
| 腰 | 性别 / 身材 / 年龄 |
| 下摆 | 身份等级（长＝正式 / 高位，短＝行动 / 平民） |
| 头部（发型 + 头饰） | 人格（最快的识别信号） |

整体轮廓形状 → 感觉：

| 轮廓 | 感觉 |
|---|---|
| 尖锐三角 | 危险、权力 |
| 圆形 | 温暖、安全 |
| 细长 | 优雅、神秘 |
| 巨大肩膀 | 统治、压迫 |
| 宽松包裹 | 自由、隐藏 |

**AI 生成注意**：轮廓是 AI 一致性最稳的锚点之一。Character Sheet 提示词里应显式写出剪影特征（如 `broad angular shoulders, long high-collar coat silhouette`），比写花纹更能跨调用锁住身份。

## 4. 体型心理（视觉编码，非刻板印象）

| 体型 | 视觉暗示 | 适配角色 |
|---|---|---|
| Tall 高 | 权威、距离感、孤独 | 领导者、神秘人物 |
| Short 矮 | 灵活、亲近、聪明 | 灵巧型、机变型 |
| Heavy 厚重 | 力量、稳定、压迫 | 守护 / 阻挡 / 权力 |
| Thin 纤细 | 敏感、脆弱、优雅 | 艺术型、易碎型 |

---

## 5. 头身比例

比例直接改变"力量感"与风格定位。

| 对象 | 头身比 | 效果 |
|---|---|---|
| 成人（写实） | 7–8 头身 | 真实、可信 |
| 英雄 | 8–9 头身 | 挺拔、超群 |
| 儿童 | 4–5 头身 | 幼态、可爱 |
| 漫画 / 高度风格化 | 10 头身以上 | 时装感、非写实 |

**用法**：写实题材锁 7–8；风格化 / 英雄叙事可拉到 8–9；给 AI 生成时把目标头身比写进 prompt（如 `realistic 7.5-head proportion`），否则模型容易默认时装 9 头身，破坏写实基调。

## 6. 五官语言

影视长期使用。五官是"在观众意识到之前先读懂人"的核心载体。

**眼睛**（决定情绪 + 年龄 + 性格）
| 特征 | 感觉 |
|---|---|
| 大眼 | 年轻、单纯、开放 |
| 小眼 | 冷静、精明、克制 |
| 深眼窝 | 压迫、阅历、神秘 |

**眼距**：宽＝开放 / 天真；窄＝集中 / 危险。

**眉毛**（情绪最快通道）
| 眉形 | 感觉 |
|---|---|
| 平眉 | 稳定、理性 |
| 上挑眉 | 攻击性、自信 |
| 下垂眉 | 温柔、忧郁 |

**鼻子**（影响阶层感与年龄）：高鼻＝成熟 / 权威；圆鼻＝亲和。

**下巴**（非常重要）：宽下巴＝力量；尖下巴＝敏感 / 精致；后缩＝脆弱。

## 6b. 面部不对称（Facial Asymmetry）

真实人物极少完全对称，电影角色设计大量利用轻微不对称来增加**真实感 / 记忆点 / 个性**：一边眉毛略高、鼻梁轻微偏、嘴角习惯性偏向。

**AI 生成注意**：完全对称的脸读起来"假 / 数字人感重"。可在 prompt 里加 `subtle facial asymmetry, one eyebrow slightly higher`，但要克制——过度不对称会被部分模型渲染成畸变。

## 7. 年龄设计三变化

年龄**不是加皱纹**，是三层同时变化：

| 维度 | 年轻 | 年老 |
|---|---|---|
| 结构 | 面部脂肪丰满 | 骨骼突出、脂肪流失 |
| 质感 | 平滑、水润 | 粗糙、松弛、暗沉 |
| 动作 | 快、重心高 | 慢、重心低 |

**关键**：只改皮肤不改结构与动作，会得到"贴了皱纹贴图的年轻人"。给 AI 生成时三者都要写进 prompt。

## 8. 毛发身份系统

头发是最快的人格 / 身份信号之一。

| 维度 | 取值 → 含义 |
|---|---|
| 长短 | 短＝行动 / 纪律；长＝自由 / 艺术 / 传统 |
| 整洁 | 整齐＝控制；凌乱＝混乱 / 自由 |
| 发际线 | 影响年龄感与压力感 |
| 状态 | 湿发＝脆弱 / 亲密 / 危机时刻 |

**发型弧线（Hair Arc）**：失恋→剪短；权力增加→更精致；堕落→凌乱。发型变化是最经济的"角色变了"的视觉信号。

## 9. FACS 表情单元（情绪 → 面部动作）

**Facial Action Coding System**：肌肉分区的基础工作由瑞典解剖学家 Carl-Herman Hjortsjö（1969/70）奠定，由 Paul Ekman 与 Wallace V. Friesen 正式建立、1978 年出版、2002 年修订。它把任意表情拆成**动作单元（Action Units, AU）**——每个 AU 对应一组面部肌肉的收缩 / 放松。心理学与动画业通用。

七种普遍情绪：**快乐 / 悲伤 / 愤怒 / 恐惧 / 厌恶 / 惊讶 / 轻蔑**。

常用映射：
| 情绪 | 面部动作 |
|---|---|
| 开心 | 眉放松、嘴角上扬（AU12） |
| 愤怒 | 眉下压、眼睑收紧（AU4 + 眼周） |
| 悲伤 | 内眉抬升（AU1） |
| 恐惧 | 眼睁大、嘴张开 |
| 厌恶 | 鼻翼收缩、上唇提起 |
| 惊讶 | 眉抬、眼睁、下颌下落 |

**真笑 vs 假笑（Duchenne）**：真笑 = AU6（眼轮匝肌收缩，眼周出现挤压）+ AU12（嘴角提升）。只有 AU12、眼睛不参与＝礼貌性假笑。悬疑 / 心理戏里，"嘴笑眼不笑"是最有效的"这个人在演"信号。

**给 AI 生成的用法**：不要只写 `smiling`，写 `genuine Duchenne smile, eyes crinkling`（真）或 `polite social smile, eyes not engaged`（假），模型会给出完全不同的可信度。

## 10. 微表情

持续 **0.04–0.5 秒**的一闪表情，泄露被压抑的真实情绪。例：嘴角一瞬上扬＝隐藏的满意；一闪的皱眉＝压下去的不满。

**用途**：悬疑 / 心理 / 反转叙事里指认"人物在说谎 / 心口不一"。图像生成难以呈现"一闪"，但可用于**分镜表演设计**——在关键镜标注"此处一帧微表情"，交给视频生成或表演。

## 11. 动作签名与重心

**动作签名（Movement Signature）**：优秀角色有独特的、可复现的身体习惯，形成动作记忆。
- 侦探：走路慢、多观察、常停顿
- 战士：重心低、动作直接
- 艺术家：动作开放、手势丰富

推导链：`人物性格 → 身体习惯 → 重复动作 → 视觉记忆`。

**重心（Center of Gravity）决定气质**：
| 重心 | 气质 |
|---|---|
| 前倾 | 主动、攻击 |
| 后仰 | 自信、疏离 |
| 低重心 | 力量、稳定 |
| 高重心 | 轻盈、紧张 |

**对视频生成极重要**：AI 视频当前最大短板不是"人不好看"，而是**没有连续动作逻辑与表演节奏**。角色的动作签名 + 重心必须写进视频提示词，否则每个镜头里人的"动作性格"会漂移。

## 12. 拉班动作分析（Laban Effort）

由 Rudolf Laban（1879–1958）及其同仁创立，广泛用于舞蹈与表演训练（多所戏剧学院用它训练演员快速切换情绪的身体表现）。

**四个动作因子（Motion Factors）**，各有两极：
| 因子 | 两极 |
|---|---|
| Weight 力量 | 轻 Light ↔ 强 Strong |
| Time 时间 | 缓 Sustained ↔ 疾 Quick |
| Space 空间 | 间接 Indirect ↔ 直接 Direct |
| Flow 流动 | 自由 Free ↔ 克制 Bound |

**层级关系（源文档未说清，此处校订）**：前三个因子（Weight + Space + Time）的八种组合构成可命名的**八种 Effort / Action Drive**——Float、Punch(Thrust)、Glide、Slash、Dab、Wring、Flick、Press；**Flow 是独立叠加**的第四层质感（自由 / 克制），决定这个动作是"释放"还是"收着"。

角色气质配方示例：
- **反派（压迫型）**：Strong + Sustained + Direct ≈ **Press**，叠加 Bound flow（克制）＝沉、慢、直、收——冷酷的压迫感。
- **英雄（爆发型）**：Strong + Quick + Direct ≈ **Punch/Thrust**，叠加 Free flow ＝有力、迅捷、释放。
- **精灵 / 天真型**：Light + Quick + Indirect ≈ **Flick**，Free flow ＝轻盈、跳脱。

**用法**：为角色选 1 种主 Effort 作为动作基调，写进视频提示词的动作层，保证跨镜头的身体质感一致。

## 13. 视线设计

眼睛决定心理关系，是最省力的"权力 / 心理状态"信号。

| 视线 | 含义 |
|---|---|
| 向上 | 敬畏、祈求 |
| 向下 | 羞愧、退缩 |
| 直视 | 挑战、掌控 |
| 躲避 | 隐藏、心虚 |

**镜头行为绑定**：为每个角色定义"面对镜头 / 压力下 / 开心时"的默认视线（见第 22 节 Identity Sheet），这是数字人 / AI 角色最容易被忽略却最影响可信度的一层。

---

## 14. 静止的力量（Stillness）

高级表演大量使用：不是一直动作，而是**控制**。一个角色站着不动、只改变眼神，往往比大动作更有力量。

**用法**：不要把每个镜头都填满动作。给关键情绪镜头设计"静止 + 单一眼神变化"，对比之下更有张力。这也降低 AI 视频的一致性负担（动得越少越不容易崩）。

---

## 15. 颜色资产（Color Script）

颜色**负责叙事**，不是"这个颜色好看"。

**色彩比例（60/30/10）**：主色 60% / 辅助色 30% / 强调色 10%。每个角色建立自己的色彩资产。

**阵营 / 类型色（示例，非铁律）**：英雄＝蓝+白；反派＝黑+暗红；危险魅惑＝紫+金。多角色时用色相拉开阵营（见第 21 节）。

**色彩弧线**：颜色随剧情演变。经典的"堕落线"：白 → 灰 → 黑（如 Breaking Bad 的 Walter White：早期米色普通衬衫 → 后期黑绿强对比，颜色对应心理）。

> **色彩语言纪律（本 skill 强制）**：描述颜色时用**描述性色彩语言**而非扁平色名。
> 写"琉璃青 / 暖驼 / 雾霭灰 / 陈旧的象牙白"，不要写"蓝 / 棕 / 灰 / 白"。
> 描述性色彩同时携带材质、明度、情绪信息，AI 模型的响应质量显著更高。

> **情绪映射平衡纪律（本 skill 强制）**：色彩弧线不要只做单一负向（堕落 → 黑）。
> 正向弧线同样要能表达——如"从雾霭灰走向清透的天青"表达通透 / 成长 / 释怀。
> 分析与描述保持正负情绪的平衡覆盖，避免把角色一味病理化 / 阴暗化。

## 16. 材质 → 心理

高级服化道大量用材质表达人物。

| 材质 | 心理 |
|---|---|
| 丝绸 | 权力、欲望 |
| 皮革 | 危险、力量 |
| 棉麻 | 自然、普通 |
| 羊毛 | 传统、稳定 |
| 金属 | 科技、冷漠 |
| 旧布 | 贫困、经历 |

**原则**：一件旧皮夹克比一套新制服更有故事。材质的"新旧 + 种类"共同编码人物的处境与历史。

## 17. 磨损位置逻辑（Wear & Tear）

真实人物的衣服留有人生痕迹。关键不是"做旧"，而是**为什么旧、旧在哪**。

| 位置 | 说明 |
|---|---|
| 袖口 | 长期伏案 / 使用 |
| 鞋 | 生活方式、行走量 |
| 包角 / 提手 | 习惯性拿法 |
| 领口 | 与身体的长期摩擦 |

例：侦探外套——肩膀磨损 + 袖口旧 + 雨渍，说明"长期在外调查"。磨损必须能回答一个人生问题，否则就是无意义做旧。

---

## 18. 道具设计（Hero Prop + Prop History）

**Hero Prop / 标志道具**：重要角色必须有视觉锚点。戒指＝家族；枪＝职业；书＝思想。道具的作用不是"拿东西"，而是**强化身份、建立记忆点**。

推导链：`人物 → 习惯 → 物品 → 视觉记忆`。

**Prop History（道具的过去）**：高级道具有来历。设计时回答：谁买的？用了多久？为什么留着？——一个有历史的物件本身就在讲角色的故事。

---

## 19. 化妆心理（皮肤状态 + 老化逻辑）

化妆**不是美化，是心理表达**。

皮肤状态 → 含义：
| 状态 | 含义 |
|---|---|
| 湿润 | 年轻、健康 |
| 干燥 | 疲惫 |
| 苍白 | 疾病、恐惧 |
| 油光 | 压力、燥热 |

**老化化妆**同第 7 节：结构变化（脂肪减少）+ 颜色变化（暗沉）+ 质感变化（粗糙），三者齐动才可信。

---

## 20. 时代真实性三层（Reality Research）

历史 / 年代题材必备。不是"像那个年代"，而是找到三层真实：

1. **时代**：如 1920 年代上海的普遍视觉基调。
2. **阶层**：同年代里，富人 vs 工人的巨大差异。
3. **个人**：同阶层里，不同人格的个体差异。

**核心**：真实人物不会穿"年代标准制服"，而是 **年代 + 职业 + 个性** 的叠加。唯一例外——当角色本身就是被制度同化的符号（刻意的去个性化），才让他穿标准制服，且这本身就是一种表达。

> **现实核查纪律（本 skill 强制）**：凡涉及真实年代 / 真实品牌 / 真实技术 / 真实地域的服化道细节，**必须联网核实**，不得凭记忆脑补。历史错误会摧毁整套设计的可信度。

## 21. 对比设计四轴（Contrast Design）

多角色同框必须视觉可区分——最忌"男女主都穿黑西装"。四条常用对比轴：

| 对比轴 | 手法 |
|---|---|
| 颜色 | 黑 vs 白 / 冷 vs 暖 / 互补色相 |
| 形态 | 硬 vs 软 / 三角 vs 圆 |
| 材质 | 金属 vs 棉麻 / 光泽 vs 哑光 |
| 新旧 | 干净 vs 破旧 |

**校验**：把所有主要角色变成纯黑影排在一起，若分不清谁是谁，重设计。这条校验对 AI 生成尤其重要——模型在多角色场景里最容易把两个角色"揉成一个人"。

## 22. AI 一致性锁定与提示词结构

### Character Identity Lock（跨调用身份锁定）
AI 生成的第一难题是**角色跨调用不一致**。把以下六项冻结成 Character Sheet，作为可复用参考：

1. **Face** 脸型 + 五官特征（含不对称点）
2. **Hair** 发型 + 颜色 + 质感
3. **Body** 头身比 + 体型 + 整体轮廓
4. **Costume** 时代 + 材质 + 剪裁
5. **Color** 主色资产（60/30/10）
6. **Prop** 标志道具

### 推荐提示词结构（本 skill 输出的骨架）
```
Character:  年龄 + 身份 + 性格
Silhouette: 身体轮廓（剪影级特征）
Face:       五官语言 + 轻微不对称
Hair:       发型 + 颜色 + 质感
Costume:    时代 + 材质 + 剪裁
Color:      主色（描述性色彩语言）
Texture:    关键材质及其质感
Props:      标志道具
Body Language: 站姿 + 走路 + 手势 + 重心（视频必填）
Expression: 默认表情 / 镜头行为（面对镜头 / 压力下 / 开心时）
Lighting:   光影方向
Mood:       情绪锚点
```

### 表情库（Expression Library）
数字人 / 多镜头角色至少准备：默认 / 开心 / 愤怒 / 悲伤 / 惊讶 / 思考 / 嘲讽。每个用 FACS 描述（见第 9 节），避免只写情绪名。

### 镜头行为（Camera Behavior）
```
面对镜头：眼神稳定 / 回避（取决于性格）
压力状态：避免直视、重心变化
开心：   动作扩大、视线上扬
```
