# Stop Search Checklist

Use this checklist before declaring a Surf Pro research round complete.

## Stop Search Table

| criterion | minimum standard | current status | proof/ref | pass? |
|---|---|---|---|---|
| Mechanism coverage | Every mechanism has at least 3 usable tracking/source entries |  |  |  |
| Authority coverage | Every core mechanism has at least 1 A or strong B source |  |  |  |
| Source type coverage | Required source types are represented: official, professional media, image archive, text/context, and domain-specific types |  |  |  |
| Local text coverage | Key text sources are clipped or summarized with URL/title/date/access date |  |  |  |
| Local image coverage | Visual mechanisms have local images mapped to source page and manifest |  |  |  |
| Updateability | Core tracking URLs are recurring paths, archives, columns, official hubs, or repeatable searches |  |  |  |
| Saturation | 2-3 extra search rounds added no new high-quality source, no new mechanism, and no better original source |  |  |  |
| Risk cleanup | D sources removed or marked rejected; no unloaded screenshot/cookie/access-denied page used as proof |  |  |  |
| Team usability | Another agent/team member can continue tracking from source table and URL list |  |  |  |
| Report readiness | Findings trace to evidence cards/source table; gaps and uncertainty are named |  |  |  |

## When to Continue Searching

Continue if any of these are true:

- A mechanism has fewer than 3 usable sources.
- A core mechanism lacks A or strong B support.
- Visual claims rely only on screenshots, flat-lays, reposts, or source pages without saved images.
- Text claims rely only on titles/snippets without reading the source.
- A long-term tracking list is mostly one-off articles rather than recurring paths.
- New searches are still finding higher-quality original sources.
- Source grades are unknown.
- Discovery methods and original queries are missing.

## When to Stop the First Round

Stop the first round when:

1. All mechanisms meet the minimum source and evidence coverage.
2. Required source types are represented.
3. Local archive is traceable and organized.
4. Additional search rounds produce mostly repeats or lower-quality sources.
5. Remaining gaps are named and do not block the current report.
6. The user’s intended use can be served by the evidence collected.

## Stop Judgment Wording

Use one of:

- `complete_for_first_round`: enough coverage for current report; continue later by scheduled update.
- `partial_but_usable`: enough for directional findings; key gaps remain and are labeled.
- `not_ready`: coverage or evidence quality is insufficient; do not write final conclusions.
- `blocked`: access, permission, tooling, or user input prevents completion.
