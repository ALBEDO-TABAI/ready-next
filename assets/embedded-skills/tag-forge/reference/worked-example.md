# Worked Example：23 个 tag 收敛到 6 个

真实案例。一份题为《护肤品牌内容相关》的文档，正文是 Helena Rubinstein（赫莲娜）的品牌综合分析报告（helena rubinstein comprehensive brand analysis report），原始 tag 行有 23 个平铺标签：

```
#品牌分析 #小红书营销 #护肤品 #营销策略 #达人推广 #高端护肤 #敏感肌护肤
#功效性护肤 #抗衰老 #修护 #保湿 #美白 #成分党 #赫莲娜 #巴黎欧莱雅 #资生堂
#薇诺娜 #润百颜 #雅诗兰黛 #谷雨 #凡士林 #修丽可 #SKII
```

这行 tag 的病灶：素材库里任何一篇护肤营销文档都会长出几乎同一串标签，tag 集合彼此高度重叠，检索时无法区分"这篇"和"那几十篇"。这正是 quality gate 第 4 条要拦的情况。

## 走五步

**Step 2 通读**：主对象是赫莲娜（标题点名、篇幅主线），其余品牌以竞品对比出现；核心视角是功效性护肤赛道的品牌打法，含小红书达人投放拆解。

**Step 3 三道闸门，逐个候选裁决**：

| 原 tag | 裁决 | 去向与理由 |
|---|---|---|
| 品牌分析 | ✅ 保留（形态） | 闸门一命中，体裁判断成立 |
| 小红书营销 | ✅ 保留（领域） | 闸门一命中，文档核心视角之一 |
| 功效性护肤 | ✅ 保留（领域） | 闸门一命中，文档核心赛道定位 |
| 赫莲娜 | ✅ 保留（实体） | 主对象判则三条全中：标题点名、篇幅最高、删掉不成立 |
| 护肤品 | ❌ 降级 | 被"功效性护肤"覆盖的上位宽泛词，无区分度 |
| 营销策略 | ❌ 降级 | 宽泛词，被"小红书营销"覆盖 |
| 达人推广 | ❌ 正文关键词 | 文档一个小节的主题，不是文档定位 |
| 高端护肤 | ❌ 正文关键词 | 描述赫莲娜的属性，属于内容细节 |
| 敏感肌护肤 | ❌ 正文关键词 | 仅在薇诺娜对比段出现，非主线 |
| 抗衰老/修护/保湿/美白 | ❌ 正文关键词 ×4 | 功效小节的枚举项；若未来按功效检索需求成立，再升为 `护肤/` 二级 |
| 成分党 | ❌ 正文关键词 | 受众描述，出现一次；未来若高频可提案入 use |
| 巴黎欧莱雅/资生堂/薇诺娜/润百颜/雅诗兰黛/谷雨/凡士林/修丽可/SKII | ❌ 正文关键词 ×9 | 全部是对比提及，非主对象。**tag 回答"关于谁"，不回答"提到了谁"** |

**Step 3 补充**：用途从上下文可推"竞品研究"（用户建库目的是研究品牌打法）——闸门一命中。状态按规则打 #待整理。

**Step 4 写回**：

```
#品牌分析 #小红书营销 #功效性护肤 #赫莲娜 #竞品研究 #待整理
```

6 个 tag，配额校验：形态 1 ✓ 领域 2 ✓ 实体 1 ✓ 用途 1 ✓ 状态 1 ✓，总数 6 ∈ [3,7] ✓。

**Step 5 报告要点**：17 个被降级的词全部列入"正文关键词"随文档存档（它们仍参与全文检索，只是不占 tag 位）；9 个竞品品牌名进入实体链接候选（未来做知识图谱时是现成的边）；无新建 pending 词条。

## 这个案例说明的三件事

1. 收敛不是删信息——17 个词一个没丢，只是**从"tag 位"移到了"关键词位"**。tag 位是稀缺的检索资源，关键词位是廉价的全文资源。
2. 实体 facet 的"主对象判则"是收敛贡献最大的一条：光它一条就砍掉了 9 个 tag。
3. 遮住正文只看 6 个 tag：品牌分析体裁、小红书+功效护肤赛道、关于赫莲娜、用于竞品研究、还没精读——文档定位完整可复原。quality gate 第 3 条通过。
