# Facet Schema：四个内容维度与独立状态

一份素材的可见标签来自四个内容 facet。每个标签只属于一个 facet；工作流状态另存，不占内容标签位置。

## 内容 facet

| facet | 回答的问题 | 开放度 | 每素材配额 | 例子 |
|---|---|---|---|---|
| **形态 form** | 这份素材**是**什么 | 封闭枚举 | 恰 1 | 品牌分析、教程、案例拆解、参考资料 |
| **领域 domain** | 它**关于**什么 | 半开放 | 共享总量 | 小红书营销、功效性护肤、AI工作流 |
| **实体 entity** | 它以**谁/什么**为主要对象 | 开放但强制归一 | 共享总量 | 赫莲娜、Houdini、Claude |
| **用途 use** | 用户留着它**打算干嘛** | 半开放 | 共享总量 | KV参考、竞品研究、教学、团队分享 |

Tag Forge 自动负责的内容标签以 2-15 个为安全范围；已有手工或导入标签原样保留，不占自动标签名额。最低完成条件不是机械凑数，而是“形态恰 1 + 领域或主要实体至少 1”。

除形态恰好一个外，领域、实体和用途不设各自硬配额。标签是否保留由语义决定：它必须有直接证据、可跨文档复用，并且能新增一条独立检索路径。同义词、翻译、大小写或拼写变体归一为一个；已有具体标签时不再保留含义相同的宽泛上位词。达到 15 个后，多余候选直接忽略，不转成用户确认问题。

## 判则

### 形态 form

- 只能从当前已启用枚举中选，不自动新建
- 判断体裁功能而不是话题：“讲怎么写品牌分析的文章”是教程，不是品牌分析

### 领域 domain

- 回答“关于什么”，不吞掉实体
- 高置信新领域必须能在正文中准确回查，且未来可被多份材料复用
- 文档讲赫莲娜的小红书打法，领域是“小红书营销”，赫莲娜是实体

### 实体 entity

- 每个实体只有一个归一名称，其他写法是别名
- 只有标题/开头点名、篇幅占比高、删掉后文档不成立的主要对象才打标签
- 对比段顺带出现的品牌、人物和工具只保留为正文关键词

### 用途 use

- 只有内容或用户留存意图能证明时才选
- 无法确定就空着，不猜

## 工作流状态

`待整理 / 已精读 / 精选 / 已归档` 属于独立工作流状态。Ready 把它写入 `ready_state`；它不出现在 `tags` 中，也不参与内容完整度和 2-15 个自动标签配额。

## 命名规则

1. 有通行中文名时用中文
2. 无通行中文名或业内惯用英文时保留官方写法
3. 拼写变体进入 aliases，不各自建标签
4. 英文多词术语使用连字符
5. 评价词、宽泛词和一次性细节不入标签
6. active 标签名与别名跨词条唯一；标准名优先，别名不得同时指向两个 facet

## 写回形态

Ready 对 Markdown 使用 YAML frontmatter：

```yaml
tags:
  - 品牌分析
  - 小红书营销
  - 功效性护肤
  - 赫莲娜
  - 竞品研究
ready_state: 待整理
```

页面只把 `tags` 展示为内容标签；`ready_state` 供工作流使用。
