# 视频素材打标方法论（v0 · 只讲方法，不做执行）

> 本文回答"视频怎么纳入同一套 tag 体系"，为日后的自动化剪辑铺路。当前 tag-forge 不处理视频文件；用户丢视频进来时，指向本文并说明现状。

## 一、核心主张：镜头是原子，片子是分子

图文素材的打标原子是"一份文件"；视频必须拆成**两层原子**：

- **片级 tag**：整条视频作为一份素材，沿用五 facet 词表（形态=视频类型、领域、实体、用途、状态）。这层让视频先成为"可检索的知识素材"
- **镜头级 tag**：每个镜头作为独立原子，带自己的 tag 记录。这层才是自动化剪辑的根基——剪辑的最小操作单位是镜头，不是片子

镜头级记录的最小字段：`shot_id / 源视频 / t_in / t_out / 代表帧路径 / tags / 依据`。

## 二、镜头切分与代表帧：站在已验证的地基上

**切分**：PySceneDetect 的 ContentDetector 把帧转入 HSV 色彩空间、按相邻帧平均差异超阈值判定硬切（官方建议阈值从 27 起调）；学术管线同样在用——Shot-by-Shot（arXiv 2504.01020）用其 Adaptive Detection 切镜头，三个影视数据集上平均每镜头 3.3–3.8 秒。**此环节直接复用 video-expert-analyzer VNext 的 stage-1 输出，不重造。**

**代表帧**：每镜头内采样少量帧，按"锐度 + 亮度 + 时间多样性"加权评分选最有代表性的一帧，产出直接适配视觉-语言嵌入等下游任务（arXiv 2506.00667，已生产部署）。更进一步，InfoShot（arXiv 2603.17374）证明固定帧预算下"按镜头选帧"优于均匀采样，其策略是每镜头两帧：一帧共性代表帧 + 一帧高偏差帧（捕捉镜头内的关键变化）。

**预算参照**：有生产管线因下游多模态描述开销大，把整片采样帧数上限定在 15 张作为细节与算力的平衡点（US 12488772）。启示：帧预算是显式参数，不是越多越好。

## 三、镜头级 facet：与生成端同词典

镜头级在五 facet 之外增设**视听 facet 组**，词汇直接复用 video-prompt-forge 的"情绪-运镜一致性矩阵"——分析端和生成端用同一本词典，日后"按 tag 检索镜头 → 喂给生成端补拍"才能无损衔接：

| 视听 facet | 取值来源 | 例 |
|---|---|---|
| 景别 | 封闭枚举 | 大远景/远景/全景/中景/近景/特写/大特写 |
| 运镜 | 封闭枚举（vpf 词表） | 固定/推/拉/摇/移/跟/升降/环绕/手持 |
| 主体 | 开放归一（复用 entity 闸门） | 人物/产品/场景空镜/文字版 |
| 场景 | 半开放 | 室内-家居/室外-城市/棚拍/自然 |
| 光线 | 封闭枚举 | 日光/夜景/逆光/侧光/柔光/硬光 |
| 情绪 | 封闭枚举（vpf 情绪轴） | 宁静/温暖/紧张/悲伤/昂扬/疏离 |
| 节奏 | 由 t_out−t_in 自动分档 | 快切(<1s)/常规(1–4s)/长镜(>4s) |

纪律与图文侧一致：每个镜头 tag 附依据（画面内可见的证据），封闭枚举 facet 不新建，情绪等推断类 tag 标注置信度。

## 四、识别成本三档（"拼图"的正确位置）

"把镜头拼成一张图做识别"是成本档位，不是默认管线。三档按素材价值选择：

1. **精析档**：逐镜头单帧独立识别。精度最高，成本最高；VNext 现有的逐镜头评分即此档。适用：要进精选库、要喂自动剪辑的素材
2. **均衡档**：每 9–12 个镜头拼一张带时间码烧录的网格图，一次调用打粗标。成本约降一个数量级。已知代价：单格分辨率被摊薄，小字幕/产品细节易糊，模型偶发跨格串内容——**均衡档产出的 tag 默认置信度降一档，精选前须精析档复核**
3. **速览档**：整片一张 contact sheet，只出片级 tag，不出镜头级。适用：入库初筛、判断值不值得细拆

## 五、自动化剪辑的接口设想（留桩，不实现）

镜头级 tag 库一旦成立，自动剪辑退化为一个查询-编排问题：

```
tag 查询（景别=特写 AND 主体=产品 AND 情绪=温暖 AND 节奏=常规）
  → 命中镜头列表（跨源视频）
  → 编排规则排序（节奏曲线 / 情绪弧线 / 景别交替律）
  → 输出 EDL / FCPXML / 剪映草稿，进人工精剪
```

三个前置条件，设计词表时就要满足：① 镜头记录含精确 t_in/t_out（切分环节天然产出）；② 视听 facet 用封闭枚举（查询才可靠）；③ 与生成端同词典（缺镜头时可以用同一组 tag 直接生成补拍 prompt）。
