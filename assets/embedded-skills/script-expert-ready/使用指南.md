## 核心流程

```
故事原文 → [Step 1 专业形态建议] → [Step 2 最小确认]
         → [Step 3 剧本化提示包]
         → [Step 4 分场大纲]
         → [Step 5 标准剧本 ↔ 逐稿自检]
         → [Step 6 分镜表]（可选）
         → [Step 7 数字资产清单]（可选）
```

默认按你需要的成果连续完成。只在你要求逐步审阅、关键输入缺失或约束冲突时暂停；已有明确选择不重复确认。执行边界以 [SKILL.md](SKILL.md) 为准。

## 各 Step 输出字段细则

### Step 1：专业形态建议

AI 判断故事最适合哪种影视形态，给出推荐强度和理由：

- 长片（45-60 场，多阶段人物关系推进）
- 中短片（核心事件集中，少量场景完成主题）
- 剧集（多人物、多支线、世界观可持续展开）
- 短剧 / 微短剧（高频冲突、密集钩子、强反转）
- 实验影像 / 艺术短片（事件少，意象是核心表达）

### Step 3：剧本化提示包（默认准备，可明确跳过）

这是写剧本之前的**控制层文档**，包含 13 个字段：

1. 项目基本参数（类型、形态、基调、目标格式）
2. 结构比例建议（幕段划分、场次占比、戏剧功能）
3. 原文优先级声明（冲突以谁为准）
4. 不可改核心（人物关系、结局、关键动机、叙事气质）
5. 必须保留场景（位置、戏剧功能、可压缩程度）
6. 必须保留台词 / 动作（是否允许改写）
7. 必须保留物件 / 母题（首次出现、发展、回收方式）
8. 可调整范围（合并、压缩、内心戏转动作）
9. 禁止行为清单（明确不能做什么）
10. 剧本格式规则（场景标题、对白、微信格式）
11. 分场大纲规则（每场必写字段）
12. 剧本自检清单（生成后逐条检查）
13. 最终执行 Prompt（可复制给另一个 AI 执行）

### Step 4：分场大纲

每场包含 10 个字段的施工图：

- 场号、场景标题、出场人物
- 本场戏剧任务、开始状态、核心动作
- 情绪转折、必保台词/物件
- 场尾钩子 / 转场逻辑
- 备注（可压缩/不可压缩/可合并）

### Step 5：标准剧本 + 自检报告

- 标准剧本一稿 → 剧本一稿自检报告 → 二稿 → 二稿自检报告 → …
- 每稿自检分为三个级别：**致命问题**（必须改）、**高优先级**（>3 项建议改）、**可优化**（可选）
- 格式统一：场标题 `## 场 X｜内/外景 地点 - 时间`，对白人物名单独加粗，微信用引用格式

### Step 6：分镜表（可选执行层）

四个层级可选：

| 层级 | 名称 | 适用场景 |
|:--|:--|:--|
| A | 关键分镜表 | 概念开发、视觉骨架、AI 方向初稿 |
| B | 场级分镜表 | 拍摄执行初稿 |
| C | 逐镜头精细分镜 | 正式拍摄、AI 视频逐镜生成 |
| D | 自定义范围 | 指定场次 / 镜头密度 |

两种输出形态：

- **传统横向分镜表**：适合统筹、快速浏览、横向比较（`shotlist-template.md`）。
- **镜头信息卡**：适合 AI 视频逐镜、按镜号调用、生图/视频提示词、参考帧回填（`shot-card-format.md`）。样例见 `examples/一起养/一起养_第48场逐镜头信息卡.md`，与同场横表样例对照看。

逐镜头精细分镜额外支持：镜头目的、起幅、落幅、主体运动、画面连续性、AI 视频提示词、负面提示词。
若要按镜号生成参考帧/line art 并回填，走 `single-shot-image-workflow.md`（需环境配好生图 API；无 API 时不编造图片，标 blocker）。

### Step 7：数字资产清单（资产固化层）

四类核心资产，外加一类可选展开，用于后续 AI 视觉生成、拍摄筹备、连续性管理：

1. **角色资产**（资产 ID、外观连续性、关系绑定、出场场次）
2. **场景资产**（空间功能、视觉关键词、连续性要求）
3. **道具 / 物件资产**（叙事功能、外观状态、连续性变化）
4. **母题 / 意象资产**（主题功能、变化路径、禁止误用）
5. **（可选）角色外观连续性子表**——默认折进角色资产的「外观连续性」字段；仅当项目跨时间线/受伤/剪发/换装/年龄变化较重时，才单独展开成分阶段子表

资产采用"稳定偏好"设计：每个重要资产分配稳定 ID，主名称不漂移，版本状态明确，支持二稿/三稿后的变更记录而非重建。

## 输出文件结构

所有产物保存在 `项目名/` 目录下（默认在当前 workspace 下的 `script-expert-ready/项目名/`；带 computer use 的环境对应 `/mnt/user-data/outputs/...`）：

```
项目名/
├── 项目名_剧本化提示包.md            # Step 3：控制层文档
├── 项目名_分场大纲.md                # Step 4：分场施工图
├── 项目名_标准剧本一稿.md            # Step 5：剧本正文
├── 项目名_剧本一稿自检报告.md        # Step 5：同步自检
├── 项目名_标准剧本二稿.md            # Step 5：修订版（如有）
├── 项目名_剧本二稿自检报告.md        # Step 5：修订自检（如有）
├── 项目名_关键分镜表.md              # Step 6：A 层级
├── 项目名_场级分镜表.md              # Step 6：B 层级
├── 项目名_第X场逐镜头分镜.md         # Step 6：C 层级（单场，横表）
├── 项目名_第X场逐镜头信息卡.md       # Step 6：C 层级（单场，信息卡）
├── 项目名_第X集逐镜头分镜_批次01.md  # Step 6：C 层级（剧集分批）
├── assets/shotXX-line-art-v1.png     # 单镜参考帧 / 分镜图（如生成）
└── 项目名_数字资产清单.md            # Step 7：角色/场景/道具/母题 + 可选外观连续性子表
```

> Skill 包本身的目录结构（SKILL.md / references 9 个 / examples 等）见 [README 的「文件结构」](README.md#文件结构)，此处不重复。
