# 剧本锻造 Script Expert Ready

> 把一个好故事，锻造成能拍、能演、能交给 AI 继续生成的剧本和分镜。

**维护者**：ALBEDO-TABAI

> 本 Skill（`script-expert-ready`）改自 摇摆时间线 的 `script-forging`（剧本锻造原作），由 **ALBEDO-TABAI** 在其基础上改进。它是**独立单技能版本**，自包含完成"故事 → 剧本 / 分镜 / 数字资产"，**无需与其他 Skill 联动**。详见文末「来源与声明」。

---

## 这是什么

**剧本锻造**是一个 AI Skill——不是魔法棒，不是"一键生成好莱坞剧本"的营销噱头。它是一个经过精密设计的**工作流引擎**，把成熟故事一步一步转化为标准影视剧本、分镜方案和数字资产清单。

它的每一稿都在你眼皮底下完成，每一步都等你拍板才往下走。你始终是那个喊"咔"的人。

> AI 负责锻造，你负责判断。

---

## 核心流程

```
故事原文
  → 专业形态判断（长片？短片？还是更适合短剧？）
  → 剧本化提示包（写剧本之前的控制层文档）
  → 🔴 等你确认
  → 分场大纲（每一场的施工图）
  → 🔴 等你确认
  → 标准剧本一稿 → 自检报告
  → 标准剧本二稿 → 自检报告（如果有致命问题或高优项≥3个）
  → 🔴 等你确认
  → 分镜表（可选，关键分镜 / 场级 / 逐镜头；传统横表或信息卡两种形态）
  → 数字资产清单（可选，角色/场景/道具/母题，+ 可选角色外观连续性子表）
```

每一步都有 **🔴 CHECKPOINT**——不是因为 AI 笨，是因为**你必须决定方向**。AI 不能替你判断"这个结局对不对味"。

---

## 支持的输入

- ✅ 短篇小说（最理想）
- ✅ 中长篇片段（不确定的会标注）
- ✅ 剧情大纲 / 故事梗概（会先找缺口）
- ✅ 长会话角色扮演记录（先整理主线再使用）
- ✅ 已有剧本初稿（进入修订线或分镜线）
- ✅ 互动 / 游戏叙事文本

**不支持的**：少于 500 字的极短文本、只有概念没有故事、纯情绪堆砌。

## 输出的东西

| 模块 | 是什么 | 什么时候用 |
|:--|:--|:--|
| 专业形态建议 | AI 判断你的故事更适合长片/短片/剧集/短剧 | 决定拍什么之前 |
| 剧本化提示包 | 13 字段控制层文档，定义"什么不能改、什么必须保" | 写剧本之前，**必做** |
| 分场大纲 | 每场 10 个字段的施工图 | 写剧本正文之前 |
| 标准剧本 | 多稿迭代 + 每稿同步自检报告 | 核心产出 |
| 分镜表 | 关键分镜 / 场级 / 逐镜头精细分镜；传统横表或信息卡两种形态（可选） | 剧本确认后 |
| 单镜参考帧 | 按镜号读信息卡 → 调用你配好的生图 API → 回填参考帧（需环境有生图 API） | AI 视频/分镜出图 |

每个模块出什么、字段长什么样、CHECKPOINT 具体在哪触发，详见[使用指南](使用指南.md)。

## 怎么用

### 最偷懒的方式

```
"帮我把这篇小说锻造成标准剧本。"
```

它会自己走完：形态判断 → 提示包 → 等你确认 → 分场大纲 → 等你确认 → 剧本正文 → 自检报告。

### 只要一个环节

```
"只帮我做分场大纲，不要写剧本正文。"
"帮我把这个定稿剧本拆成逐镜头分镜，只拆第 3 场和第 8 场。"
"把第 50 场做成信息卡格式，准备 AI 视频逐镜。"
"给这个项目生成数字资产清单。"
```

### 完整全套

```
"走全流程：从这篇小说到提示包、分场、剧本、自检，再到分镜和数字资产清单。"
```

它会在每个 CHECKPOINT 暂停等你确认，确保每一步都正确。

### 故事还不够成熟？

```
"这是我的故事梗概，帮我看看够不够成熟、缺什么，再决定要不要进入剧本。"
```

如果只有概念没有故事，会先要求你补成完整的故事梗概或剧情大纲（明确主角、核心冲突、关键场景、结局、基调）再进入剧本生成。

### 不要这样用

- ❌ 丢一个概念进来——"我想写一个关于背叛的故事"——回去先想好谁背叛了谁、为什么、结果怎样
- ❌ 跳过所有 CHECKPOINT 催着 AI 一路出到底——快是快了，偏了更惨
- ❌ "能不能加点车祸？"——不能。无依据的狗血情节是明确禁止的
- ❌ 把分镜表当最终导演方案甩给剧组——分镜是执行参考，不是导演替身
