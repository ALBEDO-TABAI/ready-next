# 点阵图表手册（双风格共用）

> 组件由模板内置 JS 渲染：写声明式 `<div class="dot-chart" data-type="..." ...>`，打开页面即成图。
> 方法论基线：形态先于颜色；颜色按职责；文字永远穿文本色；调色板过校验；量化必须诚实。

## 1. 先选形态（数据的任务 → 图表类型）

| 数据要读者做什么 | 用 | 不要用 |
|---|---|---|
| 记住一个当前值 | 大数字（R04 `kpi-num` / H07 `stat-num`）+ 一行口径 | 单柱柱状图 |
| 比较 2–6 个类别的量 | `bar`（竖）；类别名长用 `hbar` | 饼图 |
| 看排名 | `hbar`（按值排序） | 多色柱 |
| 看占比（单一比例） | `waffle`（10×10 = 1 点 1%） | 两片饼 |
| 看趋势（4–12 期） | `line` | 面积堆叠 |
| 前后对照（同一指标两态） | `hbar` 两行（before 灰 / after 强调）或两个小 waffle 并置 | 双轴图 |
| >7 个类别都有意义 | 别画图：用 R07/H06 清单版式列出来 | 更多颜色 |

**禁双轴**（两套 y 轴放一张图=制造假相关）；**禁彩虹**；**禁把类别值映射成深浅**（值已经由点数编码了）。

## 2. 颜色只有一种职责分配

- **单系列**：全部点用风格主色（slot-1）。Ready=`#FF4B2B`，Human Touch=`#C85B1E`。
- **强调一项**（emphasis，最常用）：`data-hot="i"` → 第 i 项主色，其余退避灰（Ready `#C9C6BE` / Human Touch `#CDC8BC`）。"这一项涨了"的故事永远用它，不要给每项一个颜色。
- **真正的双系列**：不并排上色。改小倍数（两个并列小图，各自主色）或 before/after 两行 hbar（before 用灰=hot 只标 after）。
- **红/琥珀纪律（Human Touch）**：`#EF3E08` 与琥珀是近邻色相，**绝不同图并用**；红只在极少数"温度"页替换琥珀整图使用。
- **文字**：数值/标签由渲染器用文本色输出（`--ink`/`--ink-2`/`--ink-3`），任何时候不要手写彩色文字标签。

### 已跑过校验器的结论（validate_palette 六检）

| 组合 | 结果 |
|---|---|
| `#FF4B2B` × `#F6F5F1` / `#FFFFFF` / `#1A1B1E` | 全部 PASS（亮暗两带都在），暗页图表照用 `#FF4B2B` |
| `#FF6345`（暗页文字/发光用） | 作图表 mark 超出暗色亮度带 → **不当数据色** |
| `#C85B1E` × `#F4F3ED` / `#FFFFFF` / `#141414` | 全部 PASS |
| `#E48421` × `#F4F3ED` | 对比度 2.48 WARN → 只能在有精确数值直标时用（渲染器默认直标，但主色仍选 `#C85B1E`） |
| `#2D6A4F`（森林绿） | 彩度不足读作灰 → 不作数据色 |
| 红 `#EF3E08` + 琥珀 `#C85B1E` 并用 | 近邻色相 → 禁止 |

模板 dark 页已自动切换退避灰/未填充色，不需要手动改。

## 3. 量化诚实（点阵图的特殊责任）

点阵图把连续值量化成整点，**必须**：

1. **显式声明单位**：`data-unit="50"` `data-unit-label=" 万"` → 渲染器自动输出图例 `● = 50 万`。不写 unit 视为 1。
2. **精确值永远直标**：渲染器把 `data-values` 的原始数字标在每列/行上——图例负责"怎么读点"，直标负责"真值是多少"。两者都不许删。
3. **选 unit 让最大值落在 8–15 点**：太少读不出差异，太多点变蚊子。`unit ≈ max/12` 取整到人类单位（1/2/5/10/50…）。
4. **量化误差控制**：`round(v/unit)` 与真值偏差 >½ 点时换更细的 unit 或改 `line`。
5. **waffle 只做 0–100%**；百分比自身就是精确值。
6. **数据必须真实**：来源写进页面 `t-meta`；没有数据就不要画图表。

## 4. 组件 API

```html
<!-- 竖柱：类别对比 -->
<div class="dot-chart" data-type="bar"
     data-values="6,9,13,11,8"            必填，真实数值
     data-labels="一月,二月,三月,四月,五月"   必填，与 values 等长
     data-unit="1" data-unit-label=" 万"    图例 ● = 1 万
     data-hot="2"                          可选，强调第 3 项（0 起）；缺省=全主色
     data-dot="17" data-gap="6"            点径/点距 px（deck 建议 dot ≥ 12）
     data-anim="chart"></div>              交给 chart recipe 做点亮动效

<!-- 横条：排名 / 长类别名 -->
<div class="dot-chart" data-type="hbar" data-values="14,10,7,4"
     data-labels="渠道 A,渠道 B,渠道 C,渠道 D" data-unit="1" data-hot="0" data-dot="13"></div>

<!-- 华夫饼：占比 -->
<div class="dot-chart" data-type="waffle" data-percent="62"
     data-label="试用转化 · n=413" data-dot="14"></div>

<!-- 折线：趋势（2px 线 + 端点大点 + 终点直标） -->
<div class="dot-chart" data-type="line" data-values="20,34,29,47"
     data-labels="Q1,Q2,Q3,Q4" data-w="640" data-h="260" data-dot="11"></div>
```

尺寸建议：deck 上 `bar/hbar/waffle` 点径 12–18px；`line` 宽 560–720。图表放进 5/7 或 6/6 网格的一列，`align-items:center` 垂直居中；列数 >6 的 bar 改 hbar。

## 5. 每张图表的自检

- [ ] 有 `data-unit`（bar/hbar）且图例可见；值是真实数据，来源在页面上。
- [ ] 只有一个强调色；hot 至多 1 项；没有第二个彩色系列。
- [ ] 点径 ≥12px（deck）；总列数 ≤6（bar）/ 总行数 ≤7（hbar）。
- [ ] 数值可从直标读出精确值，不依赖数点。
- [ ] 图表讲的结论写成了页面标题（图表页的 h-xl 就是结论句）。
- [ ] 没有：双轴 / 彩虹 / 每点标数 / 手绘 SVG 文字 / 编造数据。
