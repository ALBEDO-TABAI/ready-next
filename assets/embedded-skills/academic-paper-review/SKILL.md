# Academic Paper Review

## 方法论
1. **claim**：核心 claim 是什么？是否 well-defined / falsifiable？
2. **method**：方法是否 sound？是否有未声明假设？
3. **experiment**：实验设计 vs claim 是否对齐？control / variable / metric 是否合理？
4. **statistics**：sample size / significance test / effect size 是否声明？
5. **threat to validity**：internal / external / construct / conclusion 四类威胁是否覆盖？
6. **reproducibility**：代码 / 数据 / 超参 / 计算资源是否可重现？
7. **related work**：是否漏关键引用？claim 的 novelty 是否被前人 subsume？
