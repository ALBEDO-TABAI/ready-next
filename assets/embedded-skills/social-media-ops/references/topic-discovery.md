# 选题方法论：需求探测、验证型对标与选题库运营

> 核心立场：选题不是灵感问题，是**证据问题**。好选题 = 人群任务（有人要）× 自身资产（我能讲且讲得独特）× 供给缺口（还没被讲烂）三者的交集。
> 科学底座：K26（任务视角）、K4（可模仿性）、K18（幸存者偏差）、K30（资产/脉冲两层）、K24（基线）。

## 一、锚点协议：没有锚点不选题

任何一次选题挖掘必须先立锚点，否则产出的是"任何人都能发的正确废话选题"。锚点三问：

1. **帮谁**：目标读者是谁——具体到场景身份（"要做年终述职的产品经理"是锚点，"职场人"不是）。
2. **解决什么**：TA 的高频任务、痛点、场景（K26：功能任务/情感任务/社交任务三层都要列）。
3. **凭什么是这个账号**：创作者的独特资产（职业身份、实操记录、踩坑史、独家方法、一手数据）。

锚点来源优先级：用户明示的定位 > 账号诊断得出的定位 > 当前浏览的对标账号 > 当前搜索词。什么都没有时，必须先向用户收集定位信息（至少"赛道+人群"），不允许在空锚点上硬找。

**锚点检验**：后续每个候选选题都要能回答"为什么适合**这个账号**发，而不是同赛道任何号都能发"。答不上就删。

## 二、需求信号的四个探测面

用浏览器实测，不凭空想象。四个面互补，至少走两个：

### 2.1 搜索面（意图最强的信号）
- 在目标平台搜索框输入人群词/任务词，记录**联想词**（平台用真实搜索量生成，是免费的需求词库）。
- 看搜索结果页的**互动水位**：头部结果的互动量级 = 该词的需求盘子；结果内容的发布时间分布 = 供给新鲜度（全是老内容 → 缺口信号）。
- 搜索型平台（小红书/知乎/B站/公众号）此面权重最高（K30 资产层选题主要从这里来）。

### 2.2 对标面（已验证的需求）
- 选 3-5 个同人群账号（注意：同**人群**，不必同题材），拉近 30 条内容按互动排序。
- 高表现选题聚类 → 该人群当前被验证的任务清单；连续多号出现同一聚类 = 强需求。
- 记录对标的哑火选题同样重要——帮你避开"看起来该火但没人要"的坑（K18）。

### 2.3 评论面（追问即需求）
- 翻自己与对标的高互动内容评论区，收集三类信号：追问（"求教程/求链接/第二步怎么做"）、异议（观点分歧=表达缺口）、自述（"我也是……"的场景细节）。
- 每条高频追问都是一个现成选题，且自带"已验证的兴趣人群"。

### 2.4 时效面（确定性流量窗口）
- 季节与节点任务（开学季/年终述职/报税/换季护肤）按日历前置 2-4 周布局。
- 平台活动与热点话题：只接"与锚点相关"的热点，蹭不相关热点会污染账号人群标签（K22）。

## 三、关键词矩阵法（搜索面的系统化操作）

一次挖掘构建 8-10 个关键词，公式：**关键词 = 人群/身份 × 具体任务/场景/痛点**，至少绑定两个具体要素。

配比：
- 人群×任务词 4-5 个（主力：目标读者带着任务会怎么搜，就怎么写）
- 痛点/情绪词 2-3 个（具体的翻车与焦虑场景）
- 资产词 1-2 个（直接对应创作者独特资产的话题）
- 赛道大词 ≤1 个（只用来感知整体盘子）

纪律：
- **两两有信息增量**：同义改写只占一个名额（"AI工具推荐/AI工具实测/哪个AI好用"算一个词）。
- **口语优先**：按目标人群的说法写（"怎么瘦肚子"优于"减脂方法论"）。
- **拒绝万金油**："放到任何同赛道账号都成立"的词 = 与这个账号无关，删。
- 生成后请用户确认一轮（可删可补），确认后按清单执行，不混入被删词。

## 四、验证型对标筛选（"低粉高互动"信号的正确用法）

### 4.1 原理（为什么看低粉爆款）
推荐流平台的单条分发与账号粉丝量弱耦合：内容主要靠自身的即时表现（点击率/完读/互动）逐级获得更大流量池。因此：
- **高粉账号的爆款**：归因混杂——粉丝底盘、账号信任、算法偏好都掺在里面（K21），可复制性存疑。
- **低粉账号的爆款**：几乎只能归因于"选题+呈现"本身踩中了需求，是**被平台流量投票验证过的选题红利**，且做成它的条件与普通创作者相似（K4：条件相似的示范才可模仿）。

注意这是**信号而非圣旨**：低粉爆款也可能是偶然（被大号转发、蹭中热点、平台活动加持），筛出后要人工看一眼归因。

### 4.2 操作
1. 按关键词矩阵搜索（时间范围优先近半年，保证需求新鲜度）。
2. 候选过滤：互动量过线（阈值按平台与赛道基线定，不写死通用数字，参考"高于该关键词结果页中位数 3-5 倍"）+ 作者粉丝低于阈值（常用 10 万以下作为"低粉"参考线，垂直小赛道可降至 1-5 万，以赛道实情为准）。
3. 逐条核实作者真实粉丝量与该内容在其主页的相对表现（是 TA 的常规水平还是异常爆款——异常爆款才是选题信号）。
4. **排除自己**：候选中属于用户自己账号的内容一律排除出对标池（自己的内容只用于理解资产）。
5. 目标产出 **5-8 个合格对标**。

### 4.3 预算化迭代（不够时的扩挖顺序）
1. **先翻页/换排序核实**（成本最低）：候选池没看完之前不加新词。
2. **再定向扩搜 ≤2 轮**：分析已命中的对标共性角度，朝该方向派生 2-4 个更具体的新词（不许退回大词）。
3. **仍不足则如实降级**：告知该方向近半年验证信号稀缺，用已有对标（哪怕 2-3 个）+ 高互动头部内容继续，并在产出中标注"此条对标为头部内容，参考其结构勿对标其数据"。
4. 每轮扩挖前向用户同步进度（已挖到 N 个，正朝 X 方向扩）。

### 4.4 深读与因子分离
对合格对标逐条深读（批量打开注意节奏，每批 3-4 条），提取：
- 选题切入角（同一话题它切的哪一刀）
- 标题与封面的缺口设计（K8）
- 结构与信息密度（开头承诺→峰值→结尾）
- 互动结构（赞藏评比例形态 → 它满足的是哪类价值，K14）
- **可复制因子 vs 不可复制因子**：方法、结构、角度可复制；作者的特殊身份、时机、被转发的运气不可复制。
- 同时抽看 1-2 条同关键词的哑火内容做对照（K18）：爆款有而哑火没有的特征才算候选因子。

## 五、选题产出合同

每个选题建议必须包含：
1. **标题级表述**：直接可用的标题写法（不是"可以聊聊 XX 话题"这种方向描述）。
2. **对标锚点**：绑定一条已核实的对标内容（链接/标识 + 其数据与作者量级）。无对标的灵感型选题全场 ≤1 个且明确标注"未验证"。
3. **适配理由**：为什么适合**这个账号**——绑定锚点三问中的资产项（"你有 X 经历，讲这个自带说服力"）。
4. **切入角与形式**：具体角度 + 建议形式（图文/视频/口播）+ 差异化处理（对标已验证需求，你的版本要有增量：更新的数据/更细的人群/相反的观点/更完整的步骤）。
5. **分层标签**：资产型（常青，能吃搜索长尾）/ 脉冲型（时效热点）/ 实验型（新方向试探）（K30）。
6. 整批产出附**挖掘规模陈述**：检索了几个词、扫过多少内容、核实了多少作者、几个合格对标——让用户知道结论建立在什么样本上。

## 六、选题库运营（从"给一批"到"长期有"）

- **题库三层**：资产层（目标 30-50 个常青任务题，按关键词组织）/ 脉冲层（日历驱动，提前 2-4 周）/ 实验层（每周期 1-2 个新方向探针，用小成本形式先试）。
- **下钻协议**：某选题验证成功（高于基线 3 倍）后 48 小时内跟进：派生 2-3 个子选题（更细人群/下一步任务/反向观点），把单点爆款做成系列（K16 连载养成）。
- **补库节奏**：每 2-4 周跑一轮增量挖掘（新词来自：评论区新追问、搜索联想词变化、对标上新）。
- **淘汰纪律**：连续 2 个同方向选题低于基线 1/3，该方向降级冷藏，先诊断是选题错还是呈现错（用对标数据区分：对标仍在爆 → 呈现问题；对标也凉 → 需求退潮）。

## 七、平台差异速记

- **搜索型平台（小红书/知乎/B站/公众号）**：优先资产层选题，关键词矩阵价值最大；标题要埋搜索词。
- **纯推荐流（抖音/视频号/X 的 For You）**：脉冲与情绪选题权重升高；选题要能在前 3 秒讲清钩子；搜索面信号仍有用但供给缺口逻辑弱化。
- **关注流为主（公众号订阅/微博粉丝）**：选题服务老粉留存与转发（K6 社交货币），新客获取靠"可转发选题"而非搜索。
- 同一选题跨平台使用时按平台改造（详见 platform-mechanics.md 与 growth-monetization.md），不搬运原文。
