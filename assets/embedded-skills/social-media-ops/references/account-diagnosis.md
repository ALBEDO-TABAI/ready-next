# 账号诊断方法论：证据采集、五维框架与漏斗归因

> 适用：小红书、公众号、微博、X、抖音、B站、视频号、知乎等内容账号的定位诊断与健康检查。
> 原则：**先证据后判断，先基线后评分，先瓶颈后处方**。每个结论都要能回答"依据是什么、和什么比"。
> 科学底座见 `science-foundations.md`（下文以 K 编号引用）。

## 一、诊断前置：三问定调

开始任何分析前，先通过一轮结构化提问确认（缺失会导致整个诊断跑偏）：

1. **诊断对象关系**：自己的号 / 客户或学员的号 / 对标账号拆解。
   - 自己的号 → 教练口吻，直面问题，给可执行处方。
   - 客户的号 → 先给操作者专业判断，再附一段可直接转述的话术。
   - 对标拆解 → 研究口吻：重点是"它做对了什么、哪些可借鉴、哪些不可照搬（资源/时机/人设不可复制部分）"，不做"你哪里错了"式批评（K4：可模仿性取决于条件相似度）。
2. **核心痛点与目标**：这次最想解决什么（流量上不去/不知道发什么/想转型/想变现/掉粉）；账号的商业目标（引流获客/品牌合作/知识付费/带货/纯分享）。
3. **可用资产与深度**：创作者的职业背景、专业技能、可交付的产品或服务；期望的分析深度（快扫 vs 深诊，深诊需采集更多样本、耗时更长，要提前说明）。

用户已提供的信息不重复问；用户拒答时按默认继续（对象=自己的号，深度=标准）。

## 二、证据采集协议（浏览器实证）

诊断质量的上限由样本决定。**禁止只看主页列表就下深度结论**；也禁止声称分析过未打开的内容。

### 2.1 采集清单

| 层 | 采集内容 | 用途 |
|---|---|---|
| 账号层 | 昵称、头像、简介、背景图、认证、粉丝/关注/获赞数、置顶内容 | 定位与账号基建诊断 |
| 内容列表层 | 近 20-30 条：标题/封面、互动数（赞/藏/评/转）、发布时间、内容形式 | 基线计算、节奏分析、样本挑选 |
| 内容详情层 | 精选样本的正文/脚本、封面与配图、标签、评论区 | 深度内容诊断 |
| 搜索层 | 平台内搜索账号名与代表关键词，看收录与排位 | 搜索可见性与限流排查 |
| 同行层 | 3-5 个同量级同赛道账号的列表层数据 | 建立赛道基线（K24） |

### 2.2 样本选择规则（对照设计，K18/K21）

从内容列表中选 5-8 条深读，必须覆盖三组：
- **高表现组 1-3 条**：验证"什么在起作用"；
- **近期组 2-3 条**：代表当前状态（账号可能已与爆款时期不同）；
- **低表现组 1-2 条**：与高表现组对照，分离出真正的差异因子——只看爆款是幸存者偏差（K18）。

同时记录每条样本的发布时间与形式，避免把"发布时段/形式差异"误读为"选题差异"（K21）。视频样本分析成本高，标准深度控制在 1-2 条，优先高表现视频。

### 2.3 采集纪律

- 批量打开详情页每批 3-4 条，批间停顿；触发平台验证时提示用户手动处理后续跑，不静默放弃。
- 数据缺失（如粉丝数拿不到、列表加载不全）时如实降级并在报告中标注覆盖范围。
- 只采集公开可见数据；后台数据（曝光、完读等）只能由用户提供截图或读数，外部诊断要声明"以下基于公开面数据，漏斗上游为推断"。

## 三、基线计算（评分前必做）

裸数字无意义（K24）。先算三条基线：

1. **账号自身基线**：近 20-30 条的互动中位数（用中位数不用平均数——爆款会拉爆平均值）；高于中位数 3 倍记为相对爆款，低于 1/3 记为哑火。
2. **赛道量级基线**：3-5 个同量级同赛道账号的互动中位数；得出"该账号在同侪中的位置"。
3. **互动率口径**：互动量/粉丝数 只适合粉丝主导型平台（公众号/私域）；推荐流平台（小红书/抖音）单条流量与粉丝弱相关，应主要用"互动结构比"（赞:藏:评 的形态，见 K14）与同赛道横比。

## 四、五维诊断框架

对四维模型（定位/内容/视觉/成长）的升级：把"流量获取"与"关系与信任"分开（它们经常一好一坏且药方不同），视觉并入内容工艺维度的子项。

每维打分 0-100，**必须写评分依据（引用具体证据）**。锚点：
- 20 = 该维度基本缺失或严重错误
- 40 = 有明显结构性问题，拖累整体
- 60 = 及格，无大错但平庸
- 80 = 优秀，是账号的增长引擎
- 95+ = 罕见，同赛道标杆水平（慎给）

### 维度 1：定位清晰度
检查项：
- [ ] 3 秒测试：陌生人看主页 3 秒能否说出"这号是干嘛的、为谁服务"（K15：主页是能力层）
- [ ] 简介是否包含：身份背书 + 服务人群 + 提供价值 + 关注理由（四要素）
- [ ] 内容题材集中度：近 30 条中主线题材占比 ≥60%？（垂直的实质是**受众重合**，不是题材表面一致——"职场穿搭+职场情商"受众重合即算垂直）
- [ ] 心智可占位性：定位语能否说成"我帮【谁】用【什么方式】解决【什么问题】"且该细分下确有需求盘子（K25/K26）
- [ ] 人格可感知度：能否感受到"一个具体的人"（K9），还是纯资料号

### 维度 2：内容工艺
检查项：
- [ ] 标题/封面：是否制造诚实的信息缺口（K8）；封面文字量、可读性、版式一致性（K13 视觉锤）
- [ ] 开头 3 秒/首行：是否先给"凭什么继续看"
- [ ] 结构与密度：单位时长信息增量、有无峰值设计与结尾（K12）
- [ ] 可读性：排版、句长、口语度（K11）
- [ ] 价值明确性：每条内容能通过"价值五问"中至少两问（K5）
- [ ] 互动设计：CTA 是否唯一且低门槛（K15）；收藏结构/评论缺口/点赞表达是否分别有设计（K14）

### 维度 3：流量获取
检查项：
- [ ] 相对爆款率：自身基线 3 倍以上的内容占比；爆款是否可归因、可复制（K4）
- [ ] 搜索资产：是否有内容命中高频搜索词并获得长尾流量（K30）；平台内搜账号名/关键词的收录情况
- [ ] 发布节奏：频率与稳定性（断更/爆更交替是常见病）
- [ ] 形式适配：内容形式是否吃到平台当前的分发红利（见 platform-mechanics.md）
- [ ] 哑火率与波动：哑火内容占比及其共性（时段？题材？形式？）

### 维度 4：关系与信任
检查项：
- [ ] 互动质量：评论区是"求资料/求链接"（工具关系）还是"讲自己的事/追更/玩梗"（准社会关系，K9）
- [ ] 回评习惯：作者是否回复评论、置顶运营（K10 前排社会认同）
- [ ] 粉丝构成信号：老粉复访迹象（重复 ID、称呼熟络）；转粉理由是否明确（"关注我你每周得到什么"）
- [ ] 人设资产：自我披露、一致的口头禅/栏目/记忆点积累（K13）
- [ ] 信任储备：有没有"只有 TA 能讲"的内容（独特经历/一手数据/实操记录）

### 维度 5：变现潜力
检查项：
- [ ] 前后端匹配：内容吸引的人群 = 变现需要的人群？（最高发的结构性错位：教人做 X 的号想接 X 品类广告，但受众是同行不是消费者）
- [ ] 变现基建：简介/置顶/瞬间是否有承接口；是否达到平台商业化门槛（见 growth-monetization.md）
- [ ] 客单匹配：粉丝画像的付费能力与拟售卖物是否匹配（K27：算铁杆密度，不是只看量）
- [ ] 商业内容配比与口碑：恰饭内容的比例、选品与人设一致性、评论区对商业内容的容忍度

## 五、定位四步推演（当定位维度 <60 时执行）

1. **资产盘点**：职业身份与背书 / 实操经验与踩坑 / 独特经历 / 可交付物 / 表达特质。逐项问"这在目标人群眼里值钱吗？稀缺吗？"
2. **人群锚定**：从资产反推"谁最需要我、且我对 TA 有降维优势"。人群要收窄到带可付费信号：年龄段/身份/场景/预算/已试过的无效方案（例："28-35 岁、刚接手团队、汇报卡壳的新经理"而非"职场人"）。并验证盘子：平台内搜该人群的任务词，看内容供给与互动水位（K26）。
3. **差异化提炼**：同赛道 top 与同量级各看 3-5 号，找"人无我有/人有我特"的组合标签（身份×风格×切角）。产出一句话定位语（可直接写进简介第一行的成稿，不留填空题）。
4. **变现闭环验证**：定位语 → 内容主线 → 人群 → 变现产品四点连线是否通畅；不通则回到第 2 步调整（通常是人群错了而不是内容错了）。

## 六、漏斗归因树（症状 → 查什么 → 处方）

漏斗：曝光 → 点击 → 完读/完播 → 互动 → 转粉 → 复访 → 转化（K28）。**先定位瓶颈环，只对瓶颈环开药。**

| 症状 | 先查 | 常见病因 | 处方方向 |
|---|---|---|---|
| 曝光低（小眼睛少/播放少） | 账号状态、题材、发布时间稳定性 | 违规或质量降权（先走限流自查协议，见 compliance-safety.md）；题材受众池太小；账号人群标签混乱 | 排除处罚 → 收敛题材喂稳标签 → 蹭确定性流量（热点话题/活动）测试账号是否正常 |
| 曝光正常点击低 | 封面标题 | 缺口不足（K8）/ 封面信息过载（K11）/ 同质化 | 只改封面标题做单变量迭代（K23），每版连续 5 条再评估 |
| 点击正常完读低 | 开头与结构 | 开头兑现慢、峰值缺失（K12）、密度低、时长贪长 | 前 3 秒直给承诺；砍时长；一条内容一个主题 |
| 完读正常互动低 | 价值类型与 CTA | 内容"看完就走"型、无表达缺口无收藏结构（K14）、CTA 缺失或过多（K15） | 按互动类型分别设计钩子；结尾单一 CTA |
| 互动正常转粉低 | 主页与内容一致性 | 单条爆了但主页没有"更多同类"承接；关注理由不明确 | 建栏目化/系列化（K16）；简介写清关注收益；爆款后 48 小时内跟进同主题 |
| 转粉正常复访低 | 更新节奏与栏目 | 无固定触发物（K6 Triggers）、内容无连续性 | 固定栏目+固定时间；连载与预告 |
| 有粉丝无转化 | 前后端匹配（维度 5） | 人群错位、信任不足、承接缺失 | 见 growth-monetization.md 错位三修法 |

注意：外部视角看不到曝光/完读的真值，只能用"点赞对粉丝比、评论对点赞比"等结构比例做推断，报告中要标注推断性质。有创作者后台数据时优先用后台。

## 七、十大高频结构病（快速比对清单）

1. **定位摇摆**：多条内容线互不相干，算法与用户都记不住你。
2. **人设缺失**：纯工具号，收藏高关注低，商业溢价弱（K9/K14）。
3. **前后端错位**：内容人群 ≠ 变现人群（维度 5 检查项 1）。
4. **简介浪费**：没有身份背书/人群/价值/关注理由，主页承接失败。
5. **爆款不可复制**：爆过但归因错误或没有归因，之后回到平庸（K18/K19：先排除运气与均值回归，再找可复制因子）。
6. **标题封面弱于内容**：内容 80 分包装 40 分，死在点击环。
7. **节奏混乱**：断更—爆更循环；触发物无法养成（K6/K16）。
8. **自嗨选题**：从"我想说什么"出发而非人群任务出发（K26）。
9. **数据应激**：单条数据差就推翻策略（K19/K20），或反过来从不复盘。
10. **变现急躁**：信任储备不足时高频恰饭/硬导流，透支关系并触发平台治理。

## 八、报告输出合同

诊断报告必须包含（按序）：
1. **结论先行**：一句话总判断 + 三个最重要的发现（每个发现附证据引用：具体哪条内容/哪个数据）。
2. **五维评分表**：分数 + 一句评分依据；对比赛道基线的位置。
3. **问题分级**：P0（结构性，不修其他都白做）/ P1（显著拖累）/ P2（优化项）。每个问题：症状 → 证据 → 病因假设（标注"确认/推测"）→ 处方。
4. **定位建议**（若涉及）：可直接写进简介的一句话定位语成稿 + 收窄后的人群描述（带付费信号）+ 为什么是这群人。
5. **选题落地**：3-5 个标题级选题（与该账号独特资产强绑定，"只有 TA 能这么讲"），标注先发哪类。
6. **行动清单**：7 天内 3 件事（具体到可打钩）+ 30 天路线（含验证指标与最小样本量，K20/K23）。
7. **诚实边界**：样本量、未覆盖项、推断性结论清单；预期管理（策略生效通常按周计，不承诺流量结果）。

**交付水准红线**：结论落到具象（能写进简介的定位、能直接开写的选题），不停留在"要加强人设、要提高质量"这类认知层正确话；诊断对象是"人+账号"，建议要匹配 TA 的交付能力与性格（内向创作者别硬开直播处方）。

## 九、复诊协议

- 策略调整后 2-4 周复诊（至少 6-10 条新内容，K20 最小样本）。
- 复诊对比：同口径基线变化（中位数而非单条峰值）、瓶颈环是否位移（点击修好后瓶颈常移到完读——属正常推进而非失败）。
- 防误判：单条爆款/哑火不推翻方向（K19）；连续两个周期同向变化才升级结论（K23）。
