# 数据复盘方法论：指标体系、复盘协议与实验设计

> 定位：把"看数据"从应激反应变成有纪律的决策流程。统计防坑卡（K18-K24）在这里全部落地。
> 立场：数据是用来定位瓶颈与验证假设的，不是用来奖惩心情的。

## 一、指标体系

### 1.1 两类视角
- **外部可见指标**（任何账号都能看）：点赞、收藏、评论、转发、粉丝数、（部分平台）播放/阅读量。
- **创作者后台指标**（仅本人）：曝光/推荐量、点击率（封面点击/阅读比）、完读率/完播率、主页访问、关注来源、粉丝画像。
- 外部诊断只能用可见指标 + 结构比推断上游，报告必须声明推断性质；用户能提供后台截图/读数时优先用后台。

### 1.2 结构比（外部视角的主力工具）
绝对数受曝光规模支配，**比例形态**才反映内容性质（K14）：
- **藏赞比高**（收藏≈或＞点赞）：工具型内容，"资料价值>人的价值"——利于流量，弱于关系；账号长期全是这种形态要警惕转粉与商业化弱（配合 K9 诊断）。
- **评赞比高**：话题性强/有表达缺口，或人设内容健康信号；但也可能是争议翻车，看评论情感方向。
- **转赞比高**：社交货币型内容（K6），破圈信号。
- **赞高藏评双低**："替我说话"型轻共鸣，流量好但沉淀浅。
- 用同账号历史与同赛道同类型内容做形态基准，不跨类型比（教程和 vlog 的健康形态不同，K21）。

### 1.3 粉丝指标
- 看**净增结构**：新增 - 取关；爆款期新增多但取关也多 = 流量人群与账号人群错位信号。
- 看**来源**（有后台时）：搜索关注（资产层生效）vs 推荐关注（脉冲生效）vs 主页关注（承接生效）。
- 粉丝量本身是虚荣指标（K22），阶段目标见 K29。

## 二、单条复盘协议

发布后 T+1（初速）与 T+7（长尾）两次快照，走四步：

1. **对基线**：与账号近 30 条中位数比（K24），落在哪个带：爆款（>3×）/ 正常（1/3×–3×）/ 哑火（<1/3×）。正常带的内容不需要复盘仪式，攒着做周期分析。
2. **先排统计**：是首条数据？样本期够吗（发布不足 24h 别下结论）？上一条是爆款吗（均值回归预期，K19）？发布时段异常吗（K21）？
3. **再做归因假设**：用漏斗归因树（account-diagnosis.md §6）定位瓶颈环，只对瓶颈环提假设；每个假设标注"可验证方式"。
4. **落记录**：写进数据账本（见 §5），假设留给下一条内容当实验变量（K23）。

**爆款专用协议**：爆款是最贵的学习样本，除上述步骤外——
- 拆可复制因子 vs 不可复制因子（选题/结构/角度可复制；被大 V 转发、蹭中热点时机不可复制）；
- 找 1-2 条自己或对标的同类哑火内容做对照（K18），只有"爆款有哑火无"的特征才算候选因子；
- 48 小时内跟进：回评维护热度、发同主题下钻内容承接新粉（topic-discovery.md §6 下钻协议）；
- 预告下一条数据大概率回落（K19），防止用户误判限流。

## 三、周期复盘协议（周/双周/月）

单条看不出的东西在周期里看（K20：最小样本量）：

1. **基线趋势**：本期中位互动 vs 上期（用中位数防爆款失真）；连续两期同向变化才算趋势（K23）。
2. **分布形态**：爆款率（>3× 占比）与哑火率（<1/3× 占比）。健康形态是"中位数稳步抬升 + 偶发爆款"；"全靠一条爆款拉着，其余全哑"说明还没找到可复制模式。
3. **选题聚类表现**：按选题方向聚类算各类中位数 → 加仓有效方向、冷藏连续无效方向（topic-discovery.md §6 淘汰纪律）。
4. **形式与工艺变量**：本期实验变量（标题型/封面版式/形式/时长）的结果判定。
5. **粉丝净增结构** 与 **瓶颈环位移**：上期处方是否生效（瓶颈从点击移到完读=推进，不是失败）。
6. 产出：本期三条结论（带证据）+ 下期一到两个实验假设 + 不变项（明确"哪些继续保持"，防止过度调整）。

## 四、实验协议（把"试试看"变成可积累的认知）

每个实验五要素，缺一不做：
1. **假设**：具体且可证伪（"身份点名式标题比利益式标题对我的人群点击率更高"）。
2. **单一变量**（K23）：只动标题型/只动封面/只动发布时段/只动形式；内容主体保持同水准。
3. **最小样本**：每组 ≥3-5 条（K20），别用 1 条定胜负。
4. **观察期与口径**：T+7 数据、比什么指标（点击环实验看点击代理，别用总赞数糊）。
5. **结论分级**：显著同向 → 采纳为默认；不明确 → 再跑一轮或放弃；两次同向 → 升级为账号策略。
- 提效技巧：标题/封面是最便宜的实验位；同选题跨平台不同版本也是天然对照（记得平台本身是混杂变量，只做方向参考）。

## 五、数据账本（建议用户建立的最小记录）

每条内容一行，字段：
`日期 | 标题 | 选题方向 | 层级(资产/脉冲/实验) | 形式 | 标题钩子型 | 封面版式 | 发布时段 | T+1 赞/藏/评/转 | T+7 赞/藏/评/转 | 粉丝净增 | 备注(异常事件)`

- 价值：三个月的账本能回答几乎所有"我该发什么、怎么发"的问题，比任何外部教程都准。
- Ready 内落地：可用文档表格维护；分析时把账本作为结构化输入，直接跑周期复盘协议。

## 六、数据陷阱对照表（诊断时快速过一遍）

| 陷阱 | 症状 | 解法 |
|---|---|---|
| 幸存者偏差（K18） | 只拆爆款找"成功密码" | 强制配哑火对照组 |
| 均值回归（K19） | "爆款后必限流"论 | 回落是统计必然；限流要独立证据 |
| 小样本（K20） | 一条数据推翻策略 | 最小样本量 + 观察期 |
| 混杂变量（K21） | 把时段/热点差异读成内容差异 | 同类同期比较；单变量实验 |
| 古德哈特（K22） | 互赞群、买量、为完读牺牲内容 | 盯真实人群认可；代理指标只观察不优化 |
| 基线缺失（K24） | "点赞 200 算好吗？" | 先建账号/赛道双基线 |
| 口径混乱 | 拿曝光比阅读、拿播放比完播 | 同口径同平台比较；跨平台只比形态不比数值 |
| 注意力错配 | 天天刷实时数据 | 固定 T+1/T+7 快照 + 周期复盘，其余时间创作 |
