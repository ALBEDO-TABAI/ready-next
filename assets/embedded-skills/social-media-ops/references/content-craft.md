# 内容工艺：标题、封面、结构、互动设计与仿写协议

> 定位：单条内容的制作与优化手册。账号层问题（定位/节奏/变现）不在本文，见 account-diagnosis.md。
> 科学底座：K8（信息缺口）、K11（加工流畅性）、K12（峰终）、K13（视觉锤）、K14（互动分型）、K15（B=MAP）、K9（自我披露）。

## 一、标题工艺

### 1.1 钩子分类学（八型）
1. **痛点直击**："为什么你的笔记有赞没粉"——命名读者正在经历的困扰，越具体越准。
2. **好奇缺口**："我改了一个字，点击翻倍"——制造已知与想知的缺口（K8），必须在正文诚实填补。
3. **利益直给**："3 步做出会被收藏的封面"——给结果承诺 + 低成本暗示（数字步骤）。
4. **反差颠覆**："越想涨粉，越不能天天发"——挑战默认认知，天然带评论缺口。
5. **数字清单**："7 个被低估的选题入口"——可扫读、可收藏、显得可信。
6. **身份点名**："做知识付费的看过来"——直接圈定人群，提高精准点击（牺牲泛流量换精准，适合转化导向内容）。
7. **场景代入**："汇报前一晚还没写完 PPT 的你"——用具体场景触发"这就是我"。
8. **结果展示**："30 天从 0 到 5000 粉，我只做对了一件事"——过程证据型，需真实数据支撑。

### 1.2 纪律
- 标题承诺 = 正文交付。缺口不填补会导致完读崩+负反馈，算法侧直接反噬（K8 警告）。
- 搜索型平台在标题自然植入目标关键词（选题来自关键词矩阵时，标题就用那个词的口语形态）。
- 平台适配：小红书 20 字内可加 1-2 个 emoji；公众号克制、可长；X 第一行即标题；视频平台标题与封面文案分工不重复。
- 重要内容一次出 3-5 个不同钩子型的标题备选，标注各自类型，交用户选或做迭代测试（K23）。

## 二、封面工艺

- **3 秒可读**：手机信息流缩略图尺寸下，主文案一眼可读。封面大字 ≤12 字，一个信息点。
- **分工**：封面负责"停下来"（视觉+一个钩子），标题负责"点进来"（缺口），开头负责"看下去"（承诺）。三者不重复浪费。
- **版式一致性**（K13）：固定的字体/主色/构图模板 = 视觉锤，让老粉在信息流里认出你；同一账号封面版式不超过 2-3 套（干货版式 + 人设版式可并存）。
- 常用类型：大字报型（观点/干货）、前后对比型（教程/改造）、真人场景型（人设/生活方式）、信息图型（数据/清单，防挤爆：缩略图下必须仍可读）、悬念留白型（剧情/故事）。
- 视觉细节交给美术维度处理（构图/配色），运营侧只把关：可读性、一致性、与标题的分工。

## 三、开头工艺（黄金 3 秒 / 首行首屏）

第一句不交代背景，先给"凭什么继续看"。六种开法：
1. 抛结论（BLUF）：先给最终答案，再讲为什么。
2. 抛冲突："所有人都告诉你要日更，我停更后数据反而好了。"
3. 抛悬念：展示结果不给方法（"第三个方法最反直觉"）。
4. 点名人群 + 承诺："如果你也是 X，这条帮你解决 Y。"
5. 场景还原：一句话把人拉进具体时刻。
6. 提问打点：用读者心里正在问的问题开场。

视频加两条：前 3 秒必须有画面变化或直给主题；开头别放 logo/片头动画。

## 四、结构工艺

- **三段骨架**：钩子（承诺）→ 交付（分点/分步，信息增量递进）→ 收尾（总结金句 + 单一 CTA）。
- **峰值设计**（K12）：把最强的信息增量/情绪点放中后段；清单型内容把最猛的一条放倒数第二（"压轴"位）。
- **信息密度**：删除一切"正确的废话"；每段自检"读者读完这段多知道了什么"。长内容每 3-4 段给一个小结或小钩子（"更狠的在后面"）防流失。
- **形式模板**：
  - 图文笔记：封面 + 首图讲重点 + 中间图分步 + 尾图总结/CTA；正文短段落，每段 ≤3 行（移动端），适度 emoji 做视觉锚点（K11）。
  - 口播视频：钩子（3s）→ 立论（15s 内）→ 分点交付（每点一句结论+一个例子）→ 金句收尾 + CTA；一条只讲一件事。
  - 长文（公众号/知乎）：导语给地图（本文讲什么、读完得到什么）→ 层级分明的小标题 → 每节结论先行 → 文末总结 + 引导。

## 五、结尾与互动设计

**一条内容一个主 CTA**（K15），按内容目标选一种：
- **收藏钩**（干货/清单/教程）："这篇建议收藏，下次 X 的时候照着做。"——给"未来会用到"的理由（K14）。
- **评论钩**（观点/经历）：留表达缺口——二选一提问（"你站哪边"）、经历征集（"你遇到过最 X 的是什么"）、扣数字投票。问题要 5 秒能答。
- **转发钩**（共鸣/实用）：给转发理由（"发给那个总是 X 的朋友"）——本质是帮转发者完成社交表达（K6）。
- **关注钩**（系列/栏目）："下一篇拆 Y，关注不迷路" + 讲清关注的持续收益（"每周三更新一个模板"）。
- 发布后 1 小时内回复早期评论、置顶一条能引话题的评论（K10：前排评论是后来者的行为参照）。

## 六、人设融入工艺（干货内容的人味改造）

纯工具内容收藏高、关系浅（K9/K14）。不牺牲信息密度的人设化手法：
1. **经历披露**：方法前加一句"我踩过的坑"（"这是我第 3 次改版才明白的"）。
2. **观点披露**：在共识处敢给立场（"多数教程让你 X，我反对"）。
3. **过程披露**：展示做的过程与失败样本，不只给成品（过程感=真实感=信任）。
4. **记忆点积累**：固定口头禅、固定栏目名、固定的自称与称呼读者的方式（K13 重复曝光累积）。
5. 配比参考：人设元素融入每条干货（上述 1-4 的轻量做法）+ 每 5-10 条一条独立人设内容（故事/复盘/日常）。

## 七、仿写与改写协议

### 7.1 仿写（借鉴对标）四步
1. **拆结构**：把对标拆成结构骨架（钩子型/段落功能/峰值位置/CTA 型），丢弃其具体措辞与素材。
2. **换血肉**：用自己的主题、案例、经历、数据填充骨架；人群与场景换成自己的锚点。
3. **加增量**：必须有对标没有的东西——更新的信息/更细的步骤/相反的视角/自己的一手经验。没有增量的仿写是搬运。
4. **查相似**：成稿与对标逐段比对，措辞、例子、结构顺序高度重合处强制改写；平台查重与用户举报对搬运零容忍。

### 7.2 改稿协议
1. 先诊断后改：对照本文各节给出问题清单（标题缺口弱/开头兑现慢/结构平/CTA 缺失…），让用户知道为什么改。
2. 保留事实与作者立场；不虚构数据、经历、身份。
3. 输出：推荐版全文 + 修改说明（每处改动的依据）+ 可选的风格变体（更口语/更专业）。
4. "去 AI 味"的实质：删排比堆砌与万能形容词，加具体名词、数字与私人细节；句长要有节奏变化；允许保留一点不完美的口语。

## 八、发布前自检清单（10 项）

1. 标题有钩子且正文能兑现承诺？
2. 封面 3 秒可读、与标题不重复、版式一致？
3. 第一句给了"凭什么继续看"？
4. 通过价值五问中至少两问（K5）？
5. 有峰值内容且位置在中后段？
6. 排版适配移动端（短段落/视觉锚点）？
7. 只有一个主 CTA 且成本足够低？
8. 关键词是否自然植入（搜索型平台）？
9. 合规扫一遍：绝对化用语/特殊品类宣称/导流元素（见 compliance-safety.md）？
10. 有没有至少一处"只有我能写"的私有元素（经历/数据/观点）？
