# 点阵图表手册（卡片版 · 双风格共用）

> 与 PPT skill 同一套组件 API；本文件按 1080px 卡片尺度给参数。写声明式 `<div class="dot-chart" ...>`，模板 JS 自动渲染。

## 1. 形态选择（数据的任务 → 类型）

| 任务 | 用 | 不要用 |
|---|---|---|
| 记住一个值 | 大数字（`kpi-num`/`stat-num`）+ 口径行 | 单柱图 |
| 比较 2–6 类 | `bar`；名字长用 `hbar` | 饼图 |
| 排名 | `hbar`（按值排序） | 多色柱 |
| 单一占比 | `waffle`（1 点=1%） | 两片饼 |
| 趋势 4–12 期 | `line` | 堆叠面积 |
| 前后对照 | `hbar` 两行（after 用 hot）或两个小 waffle | 双轴 |
| >7 类都重要 | 清单卡（RC03/HC04），不画图 | 更多颜色 |

禁双轴、禁彩虹、禁按值染深浅（点数已编码值）。

## 2. 颜色纪律（已过 validate_palette 六检）

- 单系列全主色：Ready `#FF4B2B`，Human Touch `#C85B1E`（两者在各自亮/暗面全部 PASS）。
- 强调用 `data-hot="i"`：该项主色、其余退避灰——"这一项变了"的默认讲法。
- 真双系列 → 两张小图并置（小倍数），不并排上第二个彩色。
- Human Touch：红 `#EF3E08` 与琥珀近邻色相**绝不同图**；亮琥珀 `#E48421` 对比度 2.48 只能配精确直标（默认直标满足，但主色仍选 `#C85B1E`）。
- 值/标签由渲染器用文本色输出；不要手写彩色文字。

## 3. 量化诚实

1. `data-unit` 显式声明（默认 1），图例自动 `● = unit`；**图例与精确值直标都不许删**。
2. 选 unit 让最大值 8–15 点（`unit ≈ max/12` 取整到 1/2/5/10/50…）。
3. 量化误差 >½ 点换更细 unit 或改 `line`；waffle 只做 0–100%。
4. 数据必须真实，来源写在卡上（foot 或 `t-meta` 行）。

## 4. 卡片尺度参数

| 参数 | xhs/square 建议 | 说明 |
|---|---|---|
| `data-dot`（bar/hbar/waffle） | **18–22**（≥16 硬下限） | 手机上点要能看清 |
| `data-gap` | 8–10 | 点距 |
| bar 列数 | ≤5 | 再多换 hbar |
| hbar 行数 | ≤6 | 标签列自动量宽 |
| `line` | `data-w="860" data-h="360"` `data-dot="16"` | xhs 内容宽 904px |
| 图表在卡中占位 | 高度 ≤ 55% 画布 | 上结论下注，图表居中段 |

## 5. 每张图自检

- [ ] unit 图例可见；直标是真值；来源在卡上。
- [ ] 单色 + 至多一个 hot；无第二彩色系列。
- [ ] 点径 ≥16px；列/行数在上限内。
- [ ] 图表结论句就是卡标题；删掉图表标题卡还能自明就删。
- [ ] 无双轴/彩虹/每点标数/手绘 SVG 文字/编造数据。
