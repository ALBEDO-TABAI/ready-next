# 风格 H · Human Touch 温感人文（Warm Humanist）

> 信源：温感人文视觉体系（蛋壳白 + 温情红 + 琥珀谱系 + 水木明体），提炼自"有温度的生活质感"设计语言。
> 一句话定调：**有温度的生活质感**——诗人的气质，不抢不燥，内敛而优雅；版面永远让位给内容与影像。

## 0. 气质判词

遇到规范没写到的细节，按这句话裁决：**"这个处理让页面更有人的温度，还是更像广告？"** 选前者。

- 关键词：**plain truth（不加修饰的真实）· 有温度 · 安静的自信 · 手作质感 · 自然光**。
- 诗性不等于花哨：诗性来自**大留白、明体字、克制的琥珀、一句站得住的话**。
- 与 Ready 风的区别（防跑偏）：Human Touch 用**衬线明体做标题**、**直角 0 圆角**、**蛋壳白暖底**、**无 mono 等宽文化**、动效近乎无。它的精致是纸质印刷品的精致，不是仪器的精致。

### 颜色纪律（硬规则）

1. **红是温度不是装饰**：温情红只给「一页里唯一最重要的一处」——CTA、一个关键词、一枚标记。一页 ≤1 处红。
2. 琥珀承担日常强调与数据；红与琥珀是**近邻色相，绝不同时做两个数据系列**。
3. 大面积色只允许：蛋壳白、纯白、炭黑（dark 页）、琥珀渐变带（限 1 处）。
4. 不发明新颜色；语义色（成功 `#2D6A4F`/警示 `#E48421`/危险 `#B71C1C`）只配图标+文字出现。

## 2. 字体（双声部：明体的温度 × 悠黑的清晰）

```css
--serif: "ShuiMu MingTi", "水木明体", "Noto Serif SC", "Songti SC",
         "STSong", "SimSun", serif;
--sans:  "Founder YouHei", "方正悠黑", "PingFang SC", "Noto Sans SC",
         "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

（用户机器装了水木明体/方正悠黑会自动命中；没有则退到 Noto Serif SC / PingFang，气质保持。模板已挂 Google Fonts 的 Noto Serif SC + Noto Sans SC 作网络兜底。）

| 角色 | 字体 | 规格 |
|---|---|---|
| Display 大标题 | **serif** | weight 400，letter-spacing **+0.03~0.05em**，行高 1.2-1.4 |
| 小节标题 | sans | weight 500 |
| 正文 | sans | weight 400，行高 **1.75-1.8**（呼吸感是硬要求） |
| 引言/金句 | serif | weight 400，可微斜？不——**不用斜体**，用字号与留白表达 |
| 数据大数字 | **sans weight 300** | human-touch 的"临床数据"体例（32px 档起） |
| 图注/元信息 | sans | weight 400-500，12-14px 档，`--ink-2` |

排版铁律：中文标题**每行 ≤12 字**；英文**禁全大写**（保持温度）；明体不许拉伸变形；一段文字内不混多色。

## 3. 几何语言

| 元素 | 规格 |
|---|---|
| 圆角 | **0px（品牌尊严的直角）**。仅限交互控件可用 6px——幻灯片/卡片里视为不存在 |
| 阴影 | **无。** 品牌明令 logo 禁阴影，版面同守。层次靠颜色、留白、色带交替 |
| 边框 | `1px solid #E0DFD9`；强调边框 `1px solid #141414`（信物标签式） |
| 分区 | **蛋壳白 ↔ 纯白交替色带**（不画分隔线） |
| 间距 | base-4/8：`4/8/12/16/24/32/40/48/64/80`；章节级留白 64-80px 起 |
| 图片 | 直角、无阴影、不过度修饰；自然光、真实质感；`object-position` 按主体人工指定 |

## 4. 诗性表达手法（Human Touch 的身份层）

1. **金句页**：一句明体大字（≤2 行）+ 大留白 + 一行小注（出处/语境）。留白是内容，不是没排满。
2. **竖排 kicker**：章节引导词可竖排（`writing-mode: vertical-rl`，明体，letter-spacing 0.3em），立在版面左/右缘——印刷诗集的书脊感。一页 ≤1 处。
3. **信物标签**：白底 + 1px 炭黑边 + 13px 悠黑——像手作物件上的手写标签，用于关键词陈列。
4. **纸的织体**：极淡纸纹叠加（透明度 ≤0.05，静态），可有可无；绝不做动态噪点。
5. **琥珀数据**：数字是"安静实证"的语气——sans 300 大数 + 琥珀点阵图，安静地给证据。
6. **影像优先**：图好的页面，文字退到一角或一条带；**版面让位给核心内容或图像**是两种风格共同的底线，在 Human Touch 里更彻底。

## 5. 动效尺度（近乎无）

- 只允许**柔和淡入**：opacity 0→1 + 8-12px 上移，500-700ms，`cubic-bezier(.22,.61,.36,1)`，段落间 stagger 90-140ms。
- 无弹跳、无闪烁、无机械 steps、无点阵 reveal（那是 Ready 的）。图表点可做一次温和的顺序显现。
- 低功耗/静态模式下全部直接呈现。**Human Touch 的 deck 静态时不损失任何气质**——这是设计目标。

## 6. 图表语言（琥珀点阵）

详见 `dot-charts.md`。要点：主 mark `#C85B1E`（蛋壳白/白/炭黑三种面全部通过校验）；`#E48421` 亮琥珀只能配精确数值直标使用（对比度 2.48 触发 relief 规则）；多系列禁用红+琥珀并列（近邻色相），改用 emphasis 灰退避（`#CDC8BC`）或小倍数分面；before/after 用琥珀双深浅（`#C85B1E` × `#EFC355`）+ 直标。图表标题用明体，数值用 sans 300。

## 7. Do / Don't

**Do**
- 先问"这页的一句话是什么"，让那句话用明体站住，其余全部退后。
- 用蛋壳白/白色带交替做章节呼吸；用 64-80px 级留白隔开语境。
- 数据页给足出处与语境注（`--ink-2` 小字），像手写清单一样诚实。
- 图片保留自然瑕疵；人像/主体不裁关键部位，`object-position` 逐张指定。

**Don't**
- 不用圆角、不用阴影、不用玻璃拟态、不用 mono 等宽标签（那些是 Ready 的语汇）。
- 不用亮色大字压图不加处理；文字压图先做主体避让与局部同色调压暗。
- 不全大写英文；不给明体加粗到 500+；不拿红色铺面积。
- 不做华丽转场；不加与内容无关的装饰性插画、圆形贴纸、斑马纹。
- 留白不解释为"没内容"——但 3:4 信息卡仍受密度规则约束（金句/hero 页是被登记的例外，见 checklist）。
