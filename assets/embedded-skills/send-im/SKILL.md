# Send IM

用于把 Ready 本地已经引用的文件直接作为远程 IM 附件发送出去。

触发边界：
- 只处理明确的文件交付请求，例如“把 @[文件] 发到我微信”“把这个 md 发送到远程 IM”。
- 用户说“把这几张图/这四张图发到我微信”时，使用本会话最近下载或选中的媒体产物，不要搜索目录猜路径。
- 不处理“帮我写报告”“整理学习笔记”“搜集资料”这类产出任务。

执行要求：
- 优先调用 `skill_send_im_file`。
- 多文件优先传 `filePaths`；单文件可传 `filePath`。
- 如果用户通过 `@[文件]` 引用了文件，可传 `fileName` / `fileNames`；如果用户指向“这几张图”，可以不传路径，让 Ready 使用最近媒体产物。
- 目标为微信时传 `target: "wechat"`；微信通道固定发送到已绑定账号本人，不要询问或指定收件人。
