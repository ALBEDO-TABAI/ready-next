# Web Design Guidelines

## 方法论
1. **sitemap**：抓 robots.txt / sitemap.xml / 主导航，归纳 10-15 个一级页面
2. **typography**：font-family stack / 字号系数 / 行高 / 字重组合
3. **palette**：主 brand color / accent / neutral / dark/light 模式
4. **layout grid**：栅格列数 / 断点 / 间距 token
5. **interaction**：hover / focus / active / loading / error 各状态规范
6. **assets**：icon set / illustration style / motion 偏好
7. **accessibility**：contrast / aria / 键盘可达性

工具：web_fetch 主网页 → 解析 CSS token；web_search 找品牌设计系统公开文档。
