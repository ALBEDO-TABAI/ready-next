## 1. Hook 的机制

**为什么开头这么重要（真实机制）**：主流短视频平台（TikTok/抖音等）把**观看时长 / 完播率**作为分发的核心信号；视频先被推给一小批测试受众，早期留存好才会扩大分发，早期大量划走会被判为低质而限流。这个机制被大量从业观察反复印证，也符合平台已公开的排序逻辑——所以"把钩子前置、别用慢开场"是可靠原则。

**但要诚实**：网上流传的精确数字（"84.3% 的爆款在前 3 秒…""71% 的人 3 秒内决定去留"）大多来自互相援引、无法溯源的营销文章，**不是同行评审数据，不要当作事实搬运**。把"3 秒"当**经验法则**：前几秒必须给价值/钩子；具体阈值因内容、品类、平台而异。还要记住：**完播由绝对观看时长 × 留存率共同决定**，所以"越短越好"是错的——一味砍短会牺牲总时长。

**好奇心为什么起作用（有据可查）**：**George Loewenstein《The Psychology of Curiosity》(Psychological Bulletin, 1994, 116(1):75-98)** 的**信息缺口理论（information-gap theory）**：当注意力聚焦到"自己知识里的一个缺口"时，会产生一种想填补缺口的驱动力。两个对写 hook 极有用的推论：
- **好奇强度呈倒 U 形**：完全未知（缺口太大）或几乎已知（缺口太小）都不够勾人；**中等缺口最勾**。
- **受众越是已经知道大部分，越好奇那缺失的一小块**：知道 8/10 的人，比知道 2/10 的人更想知道剩下的。→ **所以强 hook 往往先给足语境、只留一个精准的小缺口，而不是把一切都藏起来。**（另有 Kang et al., 2009 的神经科学证据表明好奇会激活奖赏回路并增强记忆。）

**"每 3-5 秒变化"为什么有用（正确的机制归因）**：注意力会对**不变的刺激产生习惯化（habituation）**，而新异刺激会重新触发**朝向反应（orienting response）**——这才是"节奏变化维持注意力"的真实认知机制。（注意：常见的"Pattern Interrupt/模式打断"这个词其实源自 NLP，属被主流心理学视为伪科学的体系，**不要把它归为"行为心理学"**；用"去习惯化 / 朝向反应"来解释才准确。）

> 用于 Open Loop / 开放循环：早期资料常把"不一次讲完、留悬念"归因于 Zeigarnik 效应（未完成任务记得更牢）。但 Zeigarnik 的**记忆优势在现代研究中难以复现**（2025 年一篇系统综述与元分析发现"未完成任务无记忆优势"，仅存在"回去把它做完"的倾向）。因此开放循环更该建立在 **Loewenstein 的好奇缺口**上——制造一个受众想解决的悬而未决，而不是宣称"他们会记得更牢"。

## 2. Hook 类型（文字层）

每种给：机制 / 公式 / 示例 / 失败模式。

**A. 好奇缺口（Curiosity Gap）**
- 机制：制造中等信息缺口（见倒 U）。
- 公式：给出部分信息 + 精准隐藏关键答案。
- 示例：我花 5 万买的设备，最后发现最值钱的是这一个功能。
- 失败模式：缺口太大（不知所云）或藏成标题党（不兑现）。

**B. 反常识（Counter-intuitive）**
- 机制：大脑优先处理与预期冲突的信息。
- 公式：大众认知 + 否定 + 新解释。
- 示例：你每天涂防晒，可能正在加速皮肤老化。
- 失败模式：为反而反、正片无法自圆其说。

**C. 身份 / 权威（Authority）**
- 公式：我是 ____ / 过去 ____ 年 / 发现 ____。
- 示例：我做皮肤研究 12 年，告诉你一个很多人不知道的真相。
- 失败模式：身份与内容无关，硬贴。

**D. 数字（Number）**
- 机制：数字降低理解成本、给出明确预期。
- 示例：3 个错误 / 5 分钟学会 / 90% 的人不知道。
- 失败模式：数字与正片信息量不匹配（说 5 个只讲 2 个）。

**E. 冲突（Conflict）**
- 公式：A 认为 ____，但实际上 ____。
- 示例：很多人觉得贵的护肤品一定好，但事实刚好相反。

**F. 结果前置 / 演示优先（Demonstration-first）**
- 机制：先给"结果/反常现象"再解释，TikTok 极流行。
- 公式：结果 → 原因。
- 示例：先展示"这个玻璃杯摔不碎"，再解释为什么。

## 3. 视觉 Hook（画面层）

第一帧必须产生"视觉异常"。三大类：

**强动作开场**（适合产品/食品/科技）：液体炸开、产品掉落、手快速入镜、镜头穿越——运动直接刺激视觉注意。
**强情绪脸**：人脸是被优先处理的视觉元素（面孔捕获注意有认知科学支持），一张震惊/极端表情的脸能瞬间抓人——顺序是"表情 → 为什么？→ 产品"，而不是"产品 → 字幕"。
**强对比**：脏→净 / 旧→新 / 小→大 / 暗→亮，视觉冲突制造张力。

> 注意力"金字塔"（人脸 > 运动 > 高对比 > 文字 > 产品 > 背景）：其中"面孔与运动优先捕获注意"有实证支持，但**严格的排序与百分比是经验性简化，不是测量常数**——当经验法则用，别当定律。

## 4. 文字↔视觉 配对（关键整合）

**每一个文字 hook 都必须有一个画面 hook 与之在第一帧同时成立。** 光有文案没有视觉钩子，等于没有钩子。配对示例：

| 文字 hook | 配对的画面 hook（第一帧） |
|-----------|--------------------------|
| "你每天涂防晒，可能在加速老化" | 特写：一只涂着防晒的手，逆光下能看到皮肤纹理与细微反光 |
| "这个玻璃杯摔不碎" | 强动作：杯子从高处坠落砸地的瞬间定格 |
| "90% 油皮栽在第一步" | 强情绪脸：皱眉盯着镜子里出油额头的女生 |

STEP 2-A 的产出必须是**成对的**：文字 hook + 对应第一帧画面。

## 5. "可兑现"铁律

**hook 承诺什么，正片必须交付什么。** 承诺 A、正片给 B，是标题党——它能拉高前几秒留存，但会造成完播断崖与信任流失，长期是负资产（平台亦会因完播差而限流）。写完 hook 自问一句：**"正片真的把这个钩子兑现了吗？"** 没有就改钩子或补内容，别靠欺骗换那 3 秒。

## 6. 平台差异

- **小红书**：第一人称、干货/种草口吻，hook 偏"真诚的发现"而非强冲突（"用了 3 年才发现…"）。
- **抖音 / TikTok / Shorts**：强 hook + 完播导向，容许更强的动作/反常/冲突开场。
- **视频号**：受众偏年长，hook 更稳、少猎奇，权威/共鸣型更有效。
