# 叙事结构库（Narrative Structures）

STEP 1 选型时读此文件。每种结构给出：**一句话定位 / 最适合 / 不适合 / 节拍模板（含时间分配）/ 案例骨架 / 溯源与边界注**。

## 1. Hook–Value–Payoff（三段式）

**一句话**：为什么要看 → 你给我什么 → 结果/总结/行动。当代短视频最通用的骨架。

**最适合**：科普、教程、测评、产品讲解——几乎所有"有信息要传达"的内容。
**不适合**：纯情绪向、纯剧情向（这些更靠冲突而非信息阶梯）。

**节拍模板**（以 60s 为例，按比例缩放）：
- **Hook（0-3s，约 5%）**：抛出一个让人必须看下去的钩子。
- **Value（3-45s，约 70%）**：兑现钩子，给出真正的信息/演示/证据，是内容主体。
- **Payoff（45-60s，约 25%）**：收束成结论/正确流程/行动号召。

**案例骨架**（护肤）：
> Hook：90% 的油皮刷酸失败，都栽在被忽略的第一步。
> Value：解释角质层 / 水油平衡 / 产品正确用法与顺序。
> Payoff：正确流程 = 清洁 → 果酸 → 修护。

**边界注**：Hook–Value–Payoff 是内容创作社群沉淀出的实操命名（TikTok/YouTube 的创作者教育材料里常见），不是学术模型；它本质是"注意→满足→收束"的通用信息结构，好用但别当成有严格实证边界的定律。

## 2. PAS（Problem-Agitate-Solution）

**一句话**：指出痛点 → 放大痛苦 → 给出解法。

**最适合**：痛点型产品、痛点已经被受众感知到的品类（护肤、健康、效率工具）；种草且有明确痛点时最强。
**不适合**：受众还没意识到问题的品类（此时先做"反常识 hook"教育更有效）；纯正向品牌调性（放大痛苦会伤高级感）。

**节拍模板**：
- **Problem（引发"这就是我"）**：精准描述受众正在经历的痛。
- **Agitate（放大）**：把痛点的情绪/时间/金钱代价具象化、微观化。
- **Solution（解法）**：把产品/方法作为答案给出。

**案例骨架**（减肥）：
> 为什么你每天运动还是瘦不了？→ 因为你忽略了基础代谢下降。→ 真正有效的是调整饮食结构。

**Agitate 的视觉手法**：微观化/夸张化——把"皮肤油"放大成"油脂像覆盖城市一样铺满毛孔"。分镜上，Problem/Agitate 段用低饱和、贴脸、局部特写；Solution 段切到更亮、更稳、更高级的画面。

**边界注**：PAS 是直效营销（direct-response marketing）里的经典文案框架，与 BAB / FAB / PASTOR 同属一族。这些框架的**具体发明人多为民间口口相传、难以精确考证**——把它当成"久经使用的行业框架"即可，不要伪造某个确切出处或发明年份。它对情绪说服很有效，但缺乏 AIDA 那种覆盖全漏斗的结构性。

## 3. AIDA

**一句话**：Attention（注意）→ Interest（兴趣）→ Desire（欲望）→ Action（行动）。

**最适合**：宽泛的转化型内容、品牌+产品、需要"建立想要"的品类（香水、美妆、lifestyle）。
**不适合**：极短（<15s）内容（四段展不开）；纯干货（欲望环节会显得硬广）。

**节拍模板**（以 90s 为例）：
- **Attention（0-3s）**：制造异常，抓住注意。
- **Interest（3-30s）**：展示"为什么特殊"——拆解/实验/对比。
- **Desire（30-60s）**：制造拥有感，常用 lifestyle shot（不是喷香水的手，而是高级酒店晚宴里那个"靠近才闻得到"的气场）。
- **Action（最后）**：产品正面 + 清晰信息 + CTA。

**案例骨架**（香水）：
> 没人告诉你：女生真正喜欢的不是浓香。→ 而是靠近时才闻得到的味道。→ 这种木质东方调会让人觉得你很高级。→ 评论区告诉我你喜欢哪款。

**溯源注（可核查）**：AIDA 通常归于美国广告人 **E. St. Elmo Lewis，约 1898 年**（最早以匿名三步公式出现在 *Printers' Ink*）。学界对"是否由他独创"有争议（Strong 1925 的归因被后续研究认为证据偏弱），但作为**广告史上最早的层级效应模型（hierarchy-of-effects model）**其地位稳固。它假设消费者线性经过认知→情感→行为各阶段——这个线性假设本身也常被后来的模型（如 RACE）批评过于简化。

## 4. BAB（Before-After-Bridge）

**一句话**：原状态（差）→ 理想态（好）→ 怎么做到（桥）。

**最适合**：有**可视化前后变化**的内容——改造、功效、蜕变、装修、妆效。
**不适合**：没有清晰"前后"的抽象产品/服务。

**节拍模板**：
- **Before**：混乱/暗/低质感的原状态（视觉上低饱和）。
- **After**：干净/明亮/高级的理想态（视觉上高质感）——**先给 After 制造落差，往往比顺序讲更抓人**。
- **Bridge**：展示达成过程 / 关键步骤 / 产品。

**案例骨架**（装修）：
> 以前这个房间又暗又小。→ 改完像酒店套房。→ 关键只有三个设计。

**边界注**：同属直效营销文案框架族（见 PAS 边界注）。BAB 的杀伤力全在"落差可见"——若前后对比不够直观，它会失效，此时换 PAS 或 HVP。

## 5. 故事型：Founder Story / Hero's Journey / Story Circle

**一句话**：普通状态 → 遇到问题 → 尝试失败 → 获得方法/转机 → 改变。用叙事换取好感与信任，而非直接转化。

**最适合**：品牌故事、创始人叙事、情绪共鸣、人物向内容。目标是**认同感**时。
**不适合**：需要即时转化、时长很短、或受众只想要干货时。

**三种可用的具体骨架：**

**(a) 压缩版英雄旅程**（4-6 拍）：
> 普通状态 → 遇到问题 → 尝试失败 → 发现方法 → 改变
> 案例（创业）：三年前我负债百万 → 试过很多方法 → 直到发现一个规律 → 现在做到千万规模。

**(b) Dan Harmon 故事圈（Story Circle，8 步 · 短视频尤其好用）**：
> You（安于常态）→ Need（渴望/缺口）→ Go（进入未知）→ Search（挣扎适应）→ Find（得到想要的）→ Take（付出代价）→ Return（回到原点）→ Change（已然不同）
> 它是 Campbell 单一神话的极简化版本，8 步刚好卡进 60-90s，比 17 阶段的原版更适合短视频。

**(c) Founder / 品牌故事**：为什么做 → 遇到什么困难 → 为什么坚持 → 用户获得什么。

**溯源注（可核查）**：**英雄旅程 / 单一神话（monomyth）** 出自 **Joseph Campbell《千面英雄》(The Hero with a Thousand Faces, 1949)**，原版 17 阶段；**Christopher Vogler** 将其改写为好莱坞实用版（*The Writer's Journey*）；**Dan Harmon 的 Story Circle** 是广为流传的 8 步简化。三者都是真实且被广泛使用的结构。

## 6. 剧情 / 冲突模型

**一句话**：目标 + 阻碍 + 解决。冲突可视化是核心。

**最适合**：剧情短视频、情景广告。
**不适合**：说明性/信息性内容。

**节拍模板**（压缩三幕）：
- **第一幕（建立）**：人物 + 目标。
- **第二幕（冲突升级）**：遇到阻碍 / 尝试 / 失败。
- **第三幕（解决）**：发现产品/方法 → 解决 → 情绪释放。

**核心纪律——冲突要视觉化，不要台词化**：不要让人物说"我很生气"，而是用**摔门 / 沉默 / 停顿 / 眼神**去演。分镜上，冲突段落靠动作与留白，而非对白解释。

**案例骨架**：
> 想买高级香水 → 预算有限 → 发现平替。

**溯源注（可核查）**：**三幕结构**可上溯至亚里士多德《诗学》的"开端-中段-结尾"；现代影视版由 **Syd Field（《Screenplay》, 1979）** 与 **Robert McKee** 系统化，自 1970 年代末主导好莱坞。**Blake Snyder《Save the Cat!》(2005)** 在三幕基础上细化出 15 拍的 "Beat Sheet"（更细的节点+页码），是当代最流行的结构工具——但也正因太好套用而被批评制造"千片一面"（见第 10 节）。

---

## 7. 情绪型

**一句话**：共鸣 + 痛苦 + 释放。不卖货、不讲理，只传递一种被看见的情绪。

**最适合**：情绪向、共鸣向内容（涨粉、品牌温度）。
**不适合**：需要具体信息或转化的内容。

**节拍模板**：
- **共鸣**：说出受众心里那句没说出口的话。
- **痛苦**：把那份情绪推到最浓。
- **释放**：给一个出口/被理解的落点。

**案例骨架**：
> 成年人最大的崩溃，不是失败，而是没人知道你已经努力很久。

## 8. STAR（附注：它其实不是叙事框架）

Situation（背景）→ Task（目标）→ Action（行动）→ Result（结果）。

**重要澄清**：STAR **本质是"行为面试"里结构化回答的技巧**（帮候选人有条理地讲一段经历），并非一个原生的短视频叙事框架。它能**松散地**映射到人物/经历类内容（背景→目标→做了什么→结果），但如果你要的是故事张力，**第 5 节的英雄旅程 / Story Circle / Founder Story 是更正宗的选择**。把 STAR 当成"经历陈述的清单"而非"叙事引擎"。

## 9. 选型矩阵（目标 × 内容类型 → 结构）

| 目标 / 内容 | 首选 | 次选（构成"本质不同"的第二方案） |
|------------|------|--------------------------------|
| 种草 · 有明确痛点 | PAS | BAB（若有可视蜕变）/ HVP（干货教育） |
| 种草 · 有可视前后 | BAB | PAS / HVP |
| 转化 · 品牌+产品 | AIDA | PAS / 故事型 |
| 科普 / 教程 / 测评 | HVP | 反常识开场的 HVP 变体 |
| 品牌 / 涨粉 · 情绪 | 故事型 / 情绪型 | Founder Story |
| 剧情 / 情景广告 | 冲突模型 | 压缩三幕 |

**多方案原则**：从上表里选**策略路径真正分叉**的 1-3 个（如痛点驱动 vs 蜕变驱动 vs 教育驱动），而不是同一路径的近义变体。

## 10. 溯源与"结构崇拜"警告

**溯源纪律**：以上凡标"可核查"的（AIDA/Lewis 1898、三幕/Field 1979、Save the Cat/Snyder 2005、Monomyth/Campbell 1949），是真实存在、可查证的来源；凡直效营销文案框架（PAS/BAB/FAB/PASTOR），发明人多不可精确考证，标为"行业框架"即可。**永远不要为了显得权威而伪造出处、年份或统计数字。**

**结构崇拜警告**：结构是**生成阶段的脚手架**，不是好内容的保证。严格逐拍套模板会产出高度同质的内容——即便是最流行的 Save the Cat，也被影评人批评为把电影变成"编剧填空题（screenplay Mad Libs）"、"一旦看穿公式，所有片子开始长得一样"。因此：**用结构保证完整度与节奏基线，但永远让这一条内容的独特创意凌驾于模板之上。** 这也是本 skill 坚持给"多个本质不同的结构"而非"一个最优模板"的原因。
