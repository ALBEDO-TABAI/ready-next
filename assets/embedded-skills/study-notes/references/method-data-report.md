# Method: Data Report

用于研究摘要、市场报告、调研结果、财务/经营简报。

## What to optimize for

- 先看结论
- 再看关键数字
- 最后看这些数字能说明什么，不能说明什么

## Recommended structure

### `short`

- 最重要的发现
- 关键数字
- 一句边界提醒

### `standard`

- 先看结果
- 关键数据发现
- 这些数据说明什么
- 样本/口径/限制
- 一句话总结

### `layered`

- 一屏总览
- 分主题数据摘要
- 数据解释层
- 限制与未覆盖部分
- 一句话总结

## Analogy policy

- 默认避免
- 优先保留原始数字、样本口径、时间范围、对比对象
- 如果用户明确要求“讲人话”，也先用直白解释，不先上类比

## Credibility focus

这一类默认要写：

- 样本是谁
- 样本有多大
- 结论能覆盖到哪里
- 有没有明显偏差或未覆盖人群

## Route-specific failure modes

- 丢掉样本量、时间范围或统计口径
- 把同比、环比、百分点写混
- 把相关性写成因果
- 用解释替代数字本身
- 原文表格关键列很多时，压成模糊一句话

## Avoid

- 不要把数据和解释混成一句
- 不要为了好读省掉关键数字
- 不要把相关性写成因果
