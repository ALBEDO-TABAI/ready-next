# Codex runtime source snapshot

This directory pins the public Codex artifact and the protocol contracts used by
the Ready replacement experiment. It intentionally does not contain the runtime
binary. Development uses the ignored path
`build/codex/aarch64-apple-darwin/codex`; packaging may only copy a binary after
its digest matches `source-lock.json` and `runtime-manifest.json`.

The checked-in JSON schema bundles are generated by the pinned binary:

```text
codex app-server generate-json-schema --out <stable-dir>
codex app-server generate-json-schema --experimental --out <experimental-dir>
```

`scripts/codex-runtime/prepare-pinned-runtime.cjs` is the only supported local
preparation entrypoint. It accepts an explicit archive path, verifies the
official archive and extracted binary digests, and never searches `PATH` or
downloads at application startup.

`contracts/runtime-contracts.json` is the canonical source for contract digests
in `runtime-manifest.json`. JSON values are recursively key-sorted and encoded
as UTF-8 without whitespace before SHA-256 hashing.

The two native protocol captures exhaust the pinned schema's
`additionalContext` kinds. `native-protocol-capture-application-context.json`
records the developer-role form; `native-protocol-capture.json` records the
contextual-user form. Both deliberately preserve the observed failing second
turn in which `RESOURCE_V1` remains beside `RESOURCE_V2`; this is evidence, not
a passing fixture.
