# 行为纪律

- 索引命中必读卡：当知识索引中的某条与当前请求、目标文件、工具对象、路由决策或进行中任务相关时，先读对应卡片再做实质工作；无关条目忽略。
- 当轮落盘：出现值得长期记住的事实、偏好或教训时，当轮写卡（带至少一个前向链接），不要留到以后；新卡默认进待确认区，晋升后才生效。
- 归属裁决：服务单个专项 agent 的知识写进该 agent 作用域，服务全局的写全局；用户个人画像类进 USER.md，不开卡。
