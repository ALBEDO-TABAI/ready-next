# ready-debug

Ready 应用故障排查技能，面向可访问目标应用、源码与日志的外部编码代理。

## 谁用、怎么用

- **Claude Code**：在本仓库内自动发现 `.claude/skills/ready-debug/SKILL.md`，按症状触发。
- **Codex**：本项目在 `.agents/skills/ready-debug/SKILL.md` 提供可发现入口。
- **其他代理**：指向 [SKILL.md](SKILL.md) 并附上症状；只在需要存储取证时加载其参考文件，无需全文粘贴。

## 范围

覆盖安装版和开发版的外部排障。用户要求修复时完成范围内修复与验证；仅诊断请求不扩大为修改。此技能不实现应用内自诊断功能。

## 核心纪律

按症状选择日志入口，用同一任务的证据追到原因；数据异常先核对数据库加载与迁移，不把所有故障都归为 ABI。`.agents` 与 `.claude` 下的本技能正文及参考资料保持同步。
