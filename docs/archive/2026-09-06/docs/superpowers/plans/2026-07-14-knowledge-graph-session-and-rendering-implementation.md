# 知识图谱会话与高性能动态渲染实施计划

> 日期: 2026-07-14
> 状态: complete
> enforce: true
> 范围: 关系图谱数据读取、索引更新通知、跨入口会话、动态布局、画布绘制与文档导航恢复。

## 1. 事实与根因

用户当前主工作区的真实索引为 1393 份本地文档、320 个标签节点、约 530 条关系。现有实现存在同一根因下的四个表现：

1. `GraphView` 把图数据、视口和“允许大图”状态放在组件本地；侧栏、全局浏览和文档模式切换会卸载组件，回来后必须重新读取、重新布局，曾经确认的大图状态也随之消失。
2. `useForceLayout` 在 Renderer 主线程同步执行 240 轮 O(N²) 排斥计算；当前数据规模约需七亿次节点对计算，完成后才一次性显示，所以既阻塞又静态。
3. SVG 为每条边、每个节点和每个标签创建独立元素；图谱越大，布局、事件命中和重绘成本越高，低缩放级别仍绘制全部文字，视觉也形成文字与连线团。
4. Worker 的全景读取默认只取前 1000 份文档，聚焦读取却先加载工作区全部文档；索引完成后没有“已写入索引”的通知，持久图谱缓存无法安全判断何时失效。

## 2. 目标与边界

- T1 图谱会话独立于任何单个界面：同一查询只读取一次，侧栏与中央全局浏览复用数据、动态位置和各自视口；关闭、打开文档、切换模式后均能立即恢复。
- T2 布局在专用 Worker 中逐帧收敛，复杂度按节点、关系和局部邻域增长，不在 Renderer 做全量两两计算；拖动节点会重新加热并自然调整邻居。
- T3 使用单一 Canvas 分层绘制边、节点和按缩放级别出现的标签；低缩放隐藏普通标签，只保留节点形态，悬浮时突出关联并继续提供文档预览与点击打开。
- T4 全景一次读取最多 5000 份文档并返回总量/截断事实；聚焦查询只读取 BFS 命中的文档。相同关系去重，避免重复线条。
- T5 重建、单文档索引和文件监听增量写入完成后，由 Main 发出结构化 `document:indexChanged` 事件；Renderer 只在收到 readback 后使对应工作区图谱失效，旧图在刷新期间保持可见。

非目标：照搬 Obsidian 视觉样式、支持数十万节点同屏、为图谱增加筛选设置面板、改动文件涌现或 Agent 文件工具合同。

## 3. 实现切片

- W1 共享合同：新增索引完成事件类型；Main 的重建、单文件索引和 watcher 成功路径发事件，Preload/Renderer 暴露订阅。
- W2 数据读取：全景默认上限提升至 5000；聚焦查询改为 center row → BFS ids → 精确文档读取；返回 `totalDocs/truncated`，边去重。
- W3 持久会话：新增按 `workspaceRoot + centerPath + depth` 唯一标识的图谱会话，去重并发读取，保留旧数据刷新，缓存位置与 panel/workspace 两套视口；索引事件只失效对应工作区。
- W4 动态布局：新增可测试的线性/局部邻域模拟引擎与 Renderer Worker；确定性圆形种子、高度节点靠内、边弹簧、局部排斥、碰撞、锚点和冷却均由代码承担。拖拽时只增强一至两层关联节点的弹性，松手后局部衰减回弹，不重新搅动整张图。
- W5 画布与交互：`GraphView` 只负责生命周期、输入和预览；Canvas renderer 负责高 DPI、可见区裁剪、标签层级、命中与关联强调；节点半径按类型、连接数、节点总量和当前缩放平滑调整，全景下优先保持清晰轮廓；删除同步 O(N²) 布局与大图确认旁路。
- W6 生命周期：全局浏览和侧栏显式使用不同 view id；打开文档只关闭覆盖层，不清理图谱会话；Workbench 常驻监听索引完成事件。
- W7 索引快路：全量重建先用 size/mtime 与内容版本判断未变化文件，不再读取正文、解析并重写 tags/links/attachments；元数据变化但内容 hash 相同时只更新元数据。内容版本进入 hash 前缀，解析规则升级会自动强制一次重建。
- W8 全屏性能隔离：中央全局浏览完全覆盖工作区时，底下所有模式保留组件与滚动/菜单状态，但统一隐藏、禁用命中并暂停轮询、原生覆盖层与重绘；RSS 自动刷新完成事件只暂存最新结果，关闭后合并读回一次。
- W9 会话资源边界：Worker 输出每个显示帧最多提交一次；Worker 创建/运行失败时状态明确退化为已稳定静态图；全景会话保留，空闲聚焦会话按最近使用有界回收并终止 Worker。
- W10 索引失效精度：无变化重建、hash 相同的单文件写入和未删除到记录的 unlink 不广播图谱失效；短时间同工作区事件合并。显式单文件/Watcher 变更始终读正文并校验 hash，workspace 扫描才允许元数据快路；无变化重建仍完成待确认的 Tag Forge 索引读回。
- W11 图谱空间层级：初始位置与长期锚点按互不连通的关系簇分区，簇内保持弹性连线，簇间保留可见缓冲；空间网格始终让附近无关节点参与互斥，拖拽只向实际接触区扩散，避免恢复全量两两计算。文字按缩放、连接重要度和悬浮上下文连续渐变，并在屏幕空间做优先级避让。
- W12 图谱密度平衡：孤立节点优先使用关系簇之间和周围的空隙，不再整体追加到所有关系簇之外；缩短簇内初始半径、簇间缓冲和连线目标长度，但保留既有最小避让距离与拖拽接触区互斥。

## 4. 机器可验证合同

- C1 会话复用：同一 query 两次 mount/unmount 只调用一次 `getGraph`；panel/workspace 视口分别持久；刷新失败仍保留上一次成功图。
- C2 精确失效：其他工作区事件不触发读取；目标工作区 `rebuild/incremental` 事件只标记相应会话 stale，下一次可见时或当前有订阅时刷新。
- C3 线性布局：1700 节点/600 边的模拟步进产出有限坐标、圆形边界和可观察位移；测试同时断言每步候选检查量受局部网格约束，禁止恢复 N² 全对扫描。
- C4 动态交互：pin 后节点保持指针位置，直接邻居的位移显著大于无关节点；release 后连接距离平滑收敛，布局连续快照坐标发生变化而非一次性静态结果。
- C5 画布交互：双指移动与捏合缩放合同继续通过；命中测试能找出可点击文档节点，悬浮预览和点击进入 Document 行为继续通过。
- C6 数据完整性：真实 DB worker 测试断言文档节点携带绝对路径、全景元数据可见、重复边被去重；聚焦查询不依赖全工作区文档数组。
- C7 跨边界通知：重建、`indexDocument`、watcher add/change/unlink 的成功路径各发送一次结构化完成事件；失败路径不发送。
- C8 大文件边界：`GraphView.tsx` 收敛到 500 行以内；新引擎、会话、绘制职责分别成文件，不顺带拆分无关模块。
- C9 文件索引快路：未变化 fixture 计为 skipped，且不调用 upsert/派生表替换；内容相同但 mtime 变化只更新元数据；内容版本不匹配时必须重新读取和解析。
- C10 全景层级：1700 节点低缩放下的普通孤立点半径小于 1.8 像素；高连接节点略大但受上限约束，放大后和悬浮时再逐步增强。
- C11 覆盖层隔离：全局浏览打开时当前 Workbench mode 收到 `isActive=false`，关闭后恢复；真实 Electron 首次布局期间不再出现被覆盖 RSS 的周期重绘峰值。
- C12 会话资源：同一显示帧 10 条 Worker 位置消息只通知一次；无 Worker 的加载、拖拽和释放均保持真实 settled 状态；连续创建 20 个空闲聚焦会话后存活 Worker 不超过最近 8 个加全景会话。
- C13 精确广播：`skipped=true` 的显式索引/Watcher、`indexed=0 && removed=0` 的重建、删除 0 行的 unlink 均不发送 `document:indexChanged`。
- C14 索引反例：等长内容即使恢复原 mtime，显式单文件索引仍更新 hash 和关系；无变化 workspace 重建仍把已有 assignment 的空 `readback_at` 补齐，且不重写搜索派生表。
- C15 关系簇分离：两个互不连通的星形关系簇收敛后包围范围不重叠，连线不会跨簇穿行；同规模输入每步候选检查仍显著小于全量两两扫描。
- C16 无关节点互斥：拖拽关联链进入无关节点的最小间距时，无关节点产生可观察避让，远处节点保持稳定；释放后局部继续平滑收敛。
- C17 文字层级：1700 点全景下普通孤立点文字不可见；连接重要度和缩放只会连续提高透明度；同一区域重叠标签只保留高优先级项，悬浮文字始终可见。3625 点布局性能不得低于既有 40 ms 中位预算。
- C18 密度平衡：多个关系簇和大量孤立节点共存时，至少一部分孤立节点位于关系簇整体范围之内，禁止再次形成“中央簇群加巨大孤立外环”；真实 1713 点图谱的整体占地必须显著小于 W11 基线，同时无关节点最近距离、关系簇分离和拖拽避让合同继续通过。

专项入口：`npm run verify:knowledge-graph`；最终还需 `npm run verify:native`、`npm run build`、CSS reset gate 与真实 Electron 大索引交互验收。

## 5. 风险与回滚

- Canvas 不再为每个节点创建 DOM：既有节点本来也没有键盘访问合同；保留整体可访问名称、悬浮预览和点击路径，后续键盘图谱导航不在本次范围。
- 极端工作区超过 5000 份文档：明确返回截断事实并保持界面可用，不允许 Renderer 尝试几十万节点布局。
- Worker 不可用的测试/异常环境：使用确定性初始位置显示图谱，但不在主线程运行模拟；真实 Electron 必须验证 Worker 产物存在且持续更新。
