# Ready UI 组件与间距规范（提案）

> 日期：2026-06-14
> 状态：提案 / 未强制。本文件定纪律 + 标出现状违规；本次只把 `FileEmergenceSection`（涌现侧栏）作为试点落实，其余按「后续」分批。
> 关联：字号见 `2026-06-14-typography-token-discipline.md`；点阵/信号纪律见 `2026-06-14-nothing-borrow-plan.md`。

## 0. 现状问题（真实统计）

- **圆角无刻度**：组件里出现 `rounded-[3/4/6/7/8/9/10/12/14/16/18px]` + 命名 `rounded/-md/-lg/-xl/-2xl` 混用。最常见的 `10px(32)`、`12px(22)`、`14px(7)`、`7px(3)`、`9px(1)` 大多不在刻度上。
- **间距偶有破格**：主流 `px-3 py-2`(12/8)、`px-2 py-2`(8/8) 合规；但 `px-2.5`(10px)、`py-1.5`(6px) 这类破 4px 网格的有十几处。
- **硬边框偏多**：421 行带 `border-*`/`borderColor`，对液态玻璃「深度靠材料不靠框」的基调偏重。

## 1. 间距（4px 网格，只用 `--space-*`）

刻度：`4 · 8 · 12 · 16 · 24 · 32`（对应 `--space-1..8`）。**禁止** `px-2.5`/`py-1.5`/`10px` 等破格值。

| 场景 | 内边距 |
|---|---|
| 列表行 / 紧凑可点项 | px `6–8` · py `4` |
| 按钮（标准） | px `12` · py `8` |
| 按钮（紧凑/图标） | 见 §4 |
| 卡片 / 浮层 | `12–16` |
| 区块 section | `16–24` |

关系语义：4–8 贴合同组 / 16 同组 / 24–32 新组。**先加间距，再考虑分隔线。**

## 2. 圆角（5 档刻度 + pill；小元素用小档，pill 只给真 pill）

命名工具类 `rounded / -md / -lg / -xl / -2xl` 在 Tailwind v4 已分别等于 `4 / 6 / 8 / 12 / 16px`，优先用；裸值（`rounded-[Npx]` / `borderRadius` / `border-radius`）只许取刻度内数。

| 档 | 值 | 用途 |
|---|---|---|
| xs | `4px` | 微元素 / 紧凑徽标 / 内联标记 |
| sm | `6px` | 小 chip / tag / 小图标按钮 |
| md | `8px` | **控件 / 按钮 / 列表行 / 输入框 / 菜单项** |
| lg | `12px` | 卡片 / 面板 / 浮层 / 模态 |
| xl | `16px` | 大容器 / sheet / 大卡 |
| pill | `full` / `999` | **仅真 pill**：开关 / 头像 / 圆点 / 纯数字徽标 / 分段控件 |

铁律：
- **半径 ≤ 元素较短边的一半**，超过就读成椭圆胶囊。小按钮/小区块用 `4–8`，别用 `full`。
- `full` / `999` 只给本就该是胶囊或圆形的东西；**矩形按钮或区块禁用 `full`**（否则跑偏成胶囊）。
- 破格值 snap：`2/3→4`、`7/9/10→8`、`13/14→12`、`15→16`。
- 大值 `18/19` 要按元素判：若是**整条 pill 容器**（mode-tabs / icon-rail-slider，半径≈半高）保留为 pill（写 `full`/`999`），不要 snap 成 16。

## 3. 边框 vs 阴影 vs hairline（什么时候用外框）

- **玻璃面板 / 卡片**：默认**无硬边框**；深度靠内高光 + 柔和阴影（液态玻璃合同）。
- **列表行 / 可点项**：默认无边框；hover/selected 用 `bg + 柔和 shadow`（`--files-panel-state-*`），**不要**靠 border 出现/变色来表达状态（会跳动）。
- **分组分隔**：1px 低对比 hairline（`color-mix(... var(--text-muted) ~20%)`），而不是整圈描边。
- **硬边框只用于**：① 输入框（`--border-input`）；② 需要明确独立边界的容器卡（设置项、对话框）。其余能用间距/hairline 解决就不要加框。

## 4. 按钮（什么时候用按钮 / 什么权重）

| 类型 | 何时用 | 形态 |
|---|---|---|
| Primary 实心 | 一屏唯一主操作（发送/确认/创建） | 实色填充，圆角 8，一屏 ≤1–2 |
| Outline / Secondary | 次操作 | 1px 边框 + 透明底，圆角 8 |
| Text / Ghost | 低权重（取消/更多/链接式） | 仅文字，hover 降透明度 |
| Icon button | 工具栏 / 行内动作（刷新/关闭/展开） | 方圆，紧凑面板 `28–32px`、主工具栏 `36–38px`，圆角 8 |

铁律：
- **列表导航项不做成按钮外观**——它是导航，hover/selected 反馈即可（涌现的桶/项目/文件行属此类）。
- hover 只动 `opacity`/`background`/`translateY`，**不换色、不弹簧**（见动效纪律）。
- 饱和色只给真信号（needs-input/over-budget/error），不给普通激活态（激活态走反相/中性）。

## 5. 字号（侧栏 / 列表面）

引用字号刻度规范。侧栏惯例：

- 区块标题：`13px` / 600
- 列表行主文本：`13px` / 500（**不要 600**——满屏粗体不精致）
- 次要说明 / 摘要：`12px` / 400
- 计数 / 时间戳：`12px`，等宽（`tabular-nums` 或 numeral 角色）
- 微标签：`label` 角色（mono + 大写 + 宽字距）

## 7. 后续（按价值/风险）

1. **圆角归一**：把 `rounded-[10/14/7/9/3/18px]` 批量 snap 到 §2 四档（涉及多文件，分模块做）。
2. **去 px-2.5/py-1.5 破格**：归到 4px 网格。
3. **减硬边框**：审 421 处 border，能换 hairline/间距的换掉，硬框只留输入框 + 独立卡。
4. **按钮规整**：清点 primary 滥用，确保一屏主操作唯一。
5. 加静态 gate：禁 off-scale `rounded-[Npx]` 与 `px-2.5`/破格 padding。
