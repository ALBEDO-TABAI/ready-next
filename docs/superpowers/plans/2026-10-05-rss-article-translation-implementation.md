# RSS 文章一键翻译

## 已验证事实

- RSS 阅读页的正文是保存的 Markdown（`rss_article_content.markdown`），版本由 `body_revision`（正文哈希）标识；条目内容变化时触发器清空正文，旧派生结果随版本失效。
- RSS 的模型调用只走 `completeRSSModel`（`rss-engine/model-completion.ts`）：使用用户在设置里配置的模型，经 `requestCodexProviderText` 的网关受限单请求路径，零工具、零自动重试，调用前按上下文窗口校验。ChatGPT OAuth 的可用性与 RSS 后台判断同一判定（`processing-runtime.ts` 注入）。
- 阅读页对引用与摘句以原文版本和阅读区间为准（`rss_reference`、`readExcerpt`）；`remarkReadingAnchors` 按原文偏移给段落打锚点。
- 现有浏览器划词翻译（`fastcard-ai-service.ts`）直连服务商、上限 1400 输出 token，不适合整篇文章，不复用。

## 本轮合同

1. **只由用户发起**：阅读页“翻译”按钮触发，按篇翻译，从不自动翻译；在 Main 中运行，切换文章或关闭阅读页不中断，应用退出时取消，下次启动把未完成任务记为已取消。
2. **输入是确定版本的原文**：只翻译状态为 `ready | partial` 的已保存正文；任务与结果绑定 `(item_id, target_lang, body_revision)`。正文版本变化后旧译文不展示、不复用。
3. **切分由代码完成**：按 Markdown 顶层块切分（同一 mdast 解析）。段落、标题、列表、引用、表格可翻译；代码块、HTML、分隔线、只有图片的段落原样保留，不发送给模型。
4. **分批与输出合同**：每批不超过约 3000 个源字符或 30 块，最多两批并行。模型只返回 `{"blocks":[{"id":n,"markdown":"…"}]}`。代码逐块校验：id 恰好一一对应；译文非空；原文中的链接与图片地址、行内代码原样出现；标题级别不变。不合格的块保留原文并计为未译，不自动重试；用户可“重试未译段落”，只发送这些块。
5. **状态与进度**：`running | completed | partial | failed | cancelled`，记录已完成块数与总块数；每批落库后通知界面（`rss:translationChanged`）。模型未配置或不可用时直接给出原因，不建任务。
6. **语言**：源语言按文字比例在代码里判断；默认目标语言为简体中文，源文本是中文时默认英语；可选简体中文、English、日本語、한국어、Français、Deutsch、Español。
7. **展示**：顶栏“翻译”一键开始（外文默认译成简体中文，中文默认译成英语）；有当前版本译文后同一按钮在原文与译文之间切换，旁边的选项菜单可换目标语言、切到“对照”、查看进度、停止或重试未译段落。译文视图逐块用译文替换原文，对照视图在每个原文块下方给出译文；对照视图的目录只取原文标题。引用、摘句、保存笔记和交给助手的内容始终是原文；译文与对照视图不提供划词引用。
8. **存储**：迁移 `132_rss_article_translations` 新建 `rss_article_translations`（主键 `item_id + target_lang`，随条目删除），保存版本、状态、计数、逐块译文与错误；迁移前沿用 RSS 一致备份。

## 验证

- 单元：切分（各类块、只含图片的段落、代码块）、批次边界、输出解析（代码围栏、缺失/多余 id）、逐块校验（链接、行内代码、标题级别）、语言判断。
- 存储与服务（原生 SQLite）：完成、部分失败、取消、启动恢复、正文版本变化、重试未译段落只发送未译块、模型未配置。
- 迁移：`rss-content-migration.test.ts` 的迁移链与备份延伸到 132。
- 渲染：译文与对照视图、目录只取原文标题、译文视图关闭划词引用。
- 真实 Electron：隔离配置 + 本地假模型服务（OpenAI 兼容 Chat 真 SSE），一次点击完成翻译（1 次模型调用、5 段全部译出并落库），译文视图保留图片、代码块与链接，对照视图 5 组原文/译文且目录只列原文标题。
- 门禁：`verify:rss-workspace`（含 `verify:native`）、类型检查、受影响文件 lint。
