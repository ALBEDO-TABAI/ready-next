# 挂载文件夹里的文档可以保存

用户在真实窗口里发现：挂载进来的文件夹（W3 M4，资料库之外的文件夹）里的 Markdown 能打开、能改，却存不回去。顶栏显示“确认失败，内容已保留：Error: path is outside vault”，⌘S 也失败。用户的要求：既然能挂载，就应该允许修改；能修改，就应该能保存。

本文是这项改动的合同。先合同，后代码；每条都对应一个可运行的检查。

## 1. 根因

- 文档一被修改，Renderer 的草稿控制器就把未保存的正文交给 Main 的草稿服务做持久确认（M3 §4.1）。对已有文件，草稿记下它的对象身份和编辑前的磁盘版本（`origin: 'document'`）。
- Main 在建草稿和每次保存草稿时都要核对“磁盘上的文件是否已被别处改过”（`DocumentDraftService.baseChanged`）。这一步只是读文件、比哈希，却调用了 `checkedPath(资料库, 文件路径)`。那是草稿层写盘时用的守卫：目标必须在资料库内、路径上没有符号链接。挂载文件夹在资料库之外，于是抛出 `path is outside vault`。
- ⌘S 先确认草稿（`saveDocumentTabSnapshot` → `drafts.flush`），确认失败就不写盘。写盘本身（`document:write`）没有资料库限制，所以拦住保存的只是这一处误用的守卫。
- 旧版草稿迁移（`importLegacy`）对带路径的条目用了同一个守卫，有同样的问题。

## 2. 合同（D1–D4）

**D1 草稿对已有文件只读不写。** 核对底稿版本时，草稿层读取对象登记表里该文件的当前位置、比对哈希，不要求文件在资料库内。文件可以在资料库、挂载文件夹或其他已登记的位置。对象必须存在（`status = 'present'`）、身份无冲突，路径必须是绝对路径；否则照旧视为底稿已变（冲突），草稿保留。

**D2 草稿层自己写盘的地方不变。** 定稿目标、暂存目录、附件来源仍限当前资料库，并且路径上不能有符号链接（`checkedPath`）。把挂载文件里的草稿“保存到…”资料库内的位置，照旧生成一个新页面，原文件不动。

**D3 草稿归属不变。** 草稿记录仍按当前资料库存放、列出和恢复（`vault_root`），跨资料库读取仍返回 `wrong_vault`。挂载文件的草稿出现在当前资料库的“未保存的草稿”里。

**D4 旧版草稿迁移同 D1。** 迁移条目带的路径只要求是绝对路径，登记为对象后照旧标为冲突（旧数据没有底稿版本）。

保存后的冲突处理（“查看版本冲突”→覆盖）走页面服务的保存，那里的范围是资料库加已登记的工作区根（挂载文件夹在其中），本次不改。

## 3. 改动位置

- `src/main/modules/document-drafts/service.ts`：`baseChanged` 与 `importLegacy` 改用只读的文档位置检查（D1、D4）。
- `src/main/modules/document-drafts/files.ts`：新增 `documentPath`，只做绝对路径校验并规范化；写盘守卫 `checkedPath` 不变（D2）。

## 4. 验收

| 编号 | 检查 | 入口 |
| --- | --- | --- |
| A1 | 资料库外文件：建草稿、保存草稿成功；外部改动后保存草稿进入冲突且正文保留；冲突草稿不能定稿 | `src/__tests__/ready-draft-hierarchy-native.test.ts` |
| A2 | 资料库外文件“保存到…”资料库：生成新页面，原文件不变 | 同上 |
| A3 | 旧版草稿迁移接受资料库外的绝对路径，结果为冲突状态；相对路径被拒绝 | 同上 |
| A4 | 真实 store、草稿 IPC、SQLite 串起来：挂载文件夹里的标签修改后草稿得到确认，⌘S 写回原文件，草稿随之丢弃；重开数据库后未保存的修改能恢复 | `src/__tests__/ready-drafts-controller-native.test.ts` |
| A5 | 写盘守卫不变：定稿到资料库外、经符号链接的父目录仍被拒绝 | `ready-draft-hierarchy-native.test.ts` 既有用例 |

以上测试都在 `npm run verify:native` 内。另跑 `npm run typecheck` 与计划配对、静默 catch 两个 gate。

## 5. 不做

- 不把挂载文件夹当作“保存到…”的可选位置（那是新功能；W3 M4 规定挂载文件夹只有文件视角）。
- 不给 `document:write` 加范围限制（与本问题无关，改动面大）。
- 不改评论、同步块在挂载文件夹里的行为（W3 T2 已不出入口）。
