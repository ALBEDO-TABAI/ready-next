# 阅读模式图片分页

## 完成合同

- 沿用结构化预览与浏览器分栏，不写正文、不另建分页引擎。
- 排页前取得图片加载成功或失败的结果；取消、换文档或隐藏后，旧测量不得发布。
- 测量页、静态页与翻动页使用同一图片尺寸。图片按比例完整缩放，含外边距的占位不超出正文盒。
- 独立图片按页宽缩放后达到半页高时独占一页，前后正文保持顺序；小图随正文排列。重复出现的 Markdown 图片使用同样规则。
- 图片加载失败保留明确占位，不能阻塞其后的正文；未加载的图片不得在已定稿书页中突然撑开。
- 本地与相对图片路径沿用 `resolvePreviewReference`，重复 Markdown 图片与独立图片共用文档目录和尺寸。
- 字号、行距、页边距、窗口变化后重新排页，保持现有阅读锚点合同。

## 可执行检查

- `document-book-pagination.test.ts`：图片等比尺寸、大小图分类、加载成功/失败与取消。
- `document-book-page-face.test.tsx`：图片测量与显示共用尺寸、重复 Markdown 图片入口。
- `scripts/verify-book-image-layout.mjs`：实际 Electron 挂载阅读视图，延迟图片、重复图、连续大图、小图与失败图，检查所有页的图片边界和文字交叠，覆盖不同字号和窗口。
- `verify:document-reading`、完整 `typecheck`、CSS 层检查。
