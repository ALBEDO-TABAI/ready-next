# Ready Next W2 外壳统一：图标栏、一个侧栏、内容、助手

> 2026-11-13 注：[vvf 设计语言计划](2026-11-13-ready-next-vvf-design-language-implementation.md) §1.1 的 V13–V15 取代本文三条规则：收起后在窗口左缘悬停滑出（§2.2、§2.5 第 2 条）改为顶部留白左侧的唯一开关、图标栏当前模式图标与 `⌘B`，窄窗口下侧栏是一张浮层卡片；各导航器头部的收起 / 固定按钮删除；各模式的标签条与地址栏不移入上留白（§8“未做”），改为各功能区面板自己的头行。下文保留原样作为历史。
>
> 2026-11-13 注：按 vvf 计划 §1.2 的 V20，助手输入框上方、“选择项目”右边的模式切换槽（`DraggableModeTabs`）补回，取代 §2.4 第 1 条与 S2 的“助手面板里没有模式切换控件”；图标栏的模式图标保留，两处走同一组切换处理、显示同一个状态，S5 的模式切换入口按“图标栏 + 切换槽”计。

属于 [收束路线图](2026-11-11-ready-next-coherence-roadmap.md) 的 W2，落实 E1、E4、E5、E6、E11。证据：[b-shell](../audits/2026-11-11-ready-next-coherence-audit/b-shell.md)、[e-calendar](../audits/2026-11-11-ready-next-coherence-audit/e-calendar.md) 与实机观察 O1、O2、O4、O5、O10、O12、O15。外观遵循 [W1](2026-11-11-ready-next-w1-design-system-implementation.md)。

## 1. 现状

外壳的组件树在 `src/renderer/pages/WorkbenchMode.tsx`（967 行）：

```text
TopBar（右上角一个品牌红点）
IconRail  →  SidePanel（文件 | 搜索 | 技能中心 | 反向链接 | 关系图谱）
WorkbenchModeOutlet（四个模式，可双模式分屏）
ChatPanel（含模式切换器 DraggableModeTabs）
StatusBar（版本号与时钟）
```

问题：

- **两层导航。** 图标栏和 `SidePanel` 是全局的，在四个模式下都显示“文件管理”；每个模式内部又有自己的导航——文档的 `InkSidebar`、资讯的 `RSSNavigation`、日历的 `Sidebar`、浏览器的 `VerticalTabRail`。两层都默认 220–248px。
- **模式切换在助手面板里**（`components/agent/ChatPanel.tsx` 用 `DraggableModeTabs`），图标栏反而不管模式。助手收起后模式切换就不在视线里了。
- **重复入口**：文件树与页面树；外层搜索面板与 `⌘K`；外层“反向链接”面板与页面底部的关联面板；文档侧栏里的“主页 / AI 对话 / 日历”一行与模式切换器、助手面板重复；文档侧栏的“即将开始”与日历重复；日历自带命令面板（连按 G、K）与 `⌘K` 重复；日历自带设置与全局设置重复。
- **失效或占位**：图标栏菜单里的“用户”跳到不存在的设置分区；设置的“帐号”“通知”“语言”只改页面状态，不落盘。
- **空间**：1440 宽时正文约 36%；1100 宽时内容列约 150px。
- **快捷键冲突**：`⌘,` 在日历里打开日历设置，别处打开全局设置；`⌘\` 在日历里切换上下文栏，别处切换主题；日历帮助里仍写 `⌘K`。

## 2. 目标布局

```text
┌────┬─────────────┬───────────────────────────────┬──────────●─┐  上留白 52px
│ ○○○│ 侧栏标题     │ ‹ ›  标签条 / 地址栏            │ 助手  ⋯     │  （● 品牌红点在右上角）
├────┼─────────────┼───────────────────────────────┼────────────┤
│ 网 │ 侧栏         │                               │ 助手        │
│ 文 │ （随模式变化）│          内容                  │ （可收起）  │
│ 讯 │             │   一张纸；分屏时两张             │            │
│ 历 │             │                               │            │
│    │             │                               │            │
│ 搜 │             │                               │ ┌────────┐ │
│ 收 │             │                               │ │液态输入框│ │
├────┼─────────────┼───────────────────────────────┼─┴────────┴─┤
│ 设 │ 侧栏底部工具  │                               │            │  下留白 52px
└────┴─────────────┴───────────────────────────────┴────────────┘
 52px   248px              弹性，最小 560px            380px
```

整块是玻璃（W1 的 DL1）；只有内容区是纸或台。外框上下对称（W1 的 DL11a，用户 2026-11-11 指定）：

- **上留白 52px**（现在的 `TopBar`）：窗口拖动区。左上角是系统的窗口按钮；中间放当前模式的标签条或地址栏，与内容列对齐；侧栏标题和助手标题也在这一条里；**品牌红点保留在右上角**，点击打开今日。
- **下留白 52px**（现在的 `StatusBar` 的位置）：与上留白等高，保持安静。侧栏底部的工具和图标栏的设置按钮落在这一条里；内容列下方默认空着，只在需要时显示一行临时状态（保存中、离线、后台任务）。版本号与时钟移走（版本号在“设置 › 关于”里已有）。
- 纸、台、侧栏列表、助手消息区都落在两条留白之间；助手输入框的底边与纸的底边对齐。

### 2.1 图标栏

| 位置 | 项 | 行为 |
| --- | --- | --- |
| 上 | 浏览器、文档、资讯、日历 | 切换模式。`⌘1–4` 不变。按住 `⌥` 点击，或把图标拖进内容区，以分屏方式打开（沿用现有的分屏放置逻辑） |
| 下 | 搜索 | 打开 `⌘K` |
| 下 | 收集 | 打开 FastCard 暂存栏，角标显示暂存数量（见 W4-T5） |
| 下 | 助手 | 助手收起时显示，点击展开；助手展开时不显示 |
| 底 | 设置 | 直接进设置，不再弹出“用户 / 切换 / 设置”三项菜单 |

品牌红点不在图标栏里：它留在窗口右上角，点击打开“今日”（文档模式的系统标签页，见 W6）。

选中态按 W1 的 DL8。主题切换保留快捷键 `⌘\`，入口移到“设置 › 外观”和 `⌘K` 命令。

### 2.2 侧栏槽位

外壳只提供一个槽位，内容由当前模式提供。

| 模式 | 导航器 | 来源 |
| --- | --- | --- |
| 浏览器 | 标签列表（带标题、分组、固定），下方收藏与历史入口；助手占用的标签单列一组并显示状态（见 W7-T8） | 现有 `VerticalTabRail` 的数据与拖拽逻辑，换成带标题的列表 |
| 文档 | 资料库导航：收藏、页面树（页面 | 文件 两种视角）、挂载的文件夹、底部工具 | `InkSidebar` 与 `FilesPanel` / `FileTree` 合并，细节见 W3 |
| 资讯 | 栏目与筛子 | 现有 `RSSNavigation`，细节见 W5 |
| 日历 | 月历、图层、日历列表 | 现有日历 `Sidebar` |

规则：

- 同一时刻只挂载一个导航器。分屏时显示当前有焦点的那一侧的导航器。
- 宽度、收起状态由外壳统一保存，一个值，不分模式。范围 200–420px。
- 收起：`⌘B`。收起后鼠标移到窗口左缘可以临时滑出（沿用 ink 现有的悬停展开），移开收回。
- 导航器内部不得再放模式切换、助手入口或其他模式的摘要。

### 2.3 原来的全局面板去哪

| 原面板 | 去向 |
| --- | --- |
| 文件管理（`FilesPanel`、`FileTree`） | 并入文档导航器的“文件”视角。列表与缩略图视图、筛选、右键菜单（含网页剪藏、内容学习、文案分析、视觉分析）、颜色与图标、拖到助手，全部保留。“保存 / 导入 / 新建工作区”改为资料库与挂载文件夹的管理（W3） |
| 搜索（`GlobalSearchPanel`） | 查找对象用 `⌘K`。“在资料库中查找与替换”改为文档模式里的一个结果页（系统标签页）。“重建索引”移到“设置 › 存储” |
| 技能中心（`SkillsCenterPanel`） | 属于助手。从助手面板顶部的菜单和 `⌘K` 进入，以整页打开（与设置同级），不占侧栏 |
| 反向链接（`BacklinksCenterPanel`） | 删除。页面底部的关联面板（`RelationsPanel`）已经包含出链、反链和分组。删除前逐项核对功能，缺的补到关联面板 |
| 关系图谱（`GraphCenterPanel`） | 从文档导航器底部和 `⌘K` 打开，使用现有的全幅图谱工作区（`GraphWorkspace`）。不再挤在侧栏里（O15） |
| 文件涌现（`FileEmergenceSection`） | 今日页的一个区块（W6）；文档导航器里保留一个默认折叠的小节。反馈仍同时约束 Main 与 Renderer |

### 2.4 助手面板

- 模式切换器移出，助手面板只剩：会话头、消息、输入框。“选择项目”保留在输入框上方。
- 输入框保留液态玻璃（W1 的 DL4a），底边与纸的底边对齐。助手标题与操作在上留白里，给右上角的品牌红点让出位置。
- 默认宽 380px，范围 320–560px。`Tab` 收起或展开（不变）。
- 收起时完全不占宽度，图标栏出现“助手”按钮。
- `ChatPanel` 仍通过属性拿到当前模式用于助手的上下文，这部分数据流不变；只是不再负责切换。

### 2.5 空间不足时

内容区最小 560px，任何时候不被挤到更窄。窗口变窄时按下面的顺序让出空间：

1. 助手从并排改为浮在内容上方的抽屉（点击内容区或按 `Tab` 收回）。
2. 侧栏改为悬停滑出。
3. 仍不够时内容区横向不再缩小，窗口有最小宽度。

抽屉和滑出的侧栏属于浮层，出现时原生网页层让位（W1 的浮层规则）。

## 3. `⌘K`、设置、快捷键

### 3.1 `⌘K`

- 增加命令注册表：各模式把自己的命令登记进来，带“只在某模式下出现”的条件。日历 `commands.ts` 里的命令迁入，日历自带的命令面板（`components/CommandMenu.tsx`）与“连按 G、K”删除。
- 增加全局命令：切换主题、收起侧栏、收起助手、今日、技能中心、关系图谱、在资料库中查找与替换、新建页面 / 数据库 / 画板、打开 FastCard。
- 结果的显示规则（标题不带扩展名、类型用中文、覆盖的对象类型）在 W6 里完成。

### 3.2 设置

| 分组 | 分区 | 处理 |
| --- | --- | --- |
| 通用 | 外观、快捷键 | 外观只剩明暗与“减少透明”（W1） |
| 助手 | 模型、长期记忆、技能、MCP、模型与运行时、远程助手、宠物 | “AI 模型”与“模型与运行时”核对后合并或改名，避免两个入口讲同一件事 |
| 内容 | 资料库、阅读、资讯、日历、浏览器数据、外部服务、文档标签 | 新增“资料库”（位置、挂载文件夹、索引状态与重建）；“RSS 底稿”并入“资讯”；日历自带的偏好设置（`workbench/components/Settings.tsx`）整体搬进“日历”分区后删除原入口 |
| 隐私与数据 | 隐私、存储 | — |
| 关于 | 关于 | — |

删除：“帐号”（写死的 `Ready User / user@ready.app`）、不落盘的“通知”“语言”通用开关。通知相关的真实开关（日程提醒、资讯通知）放在各自的分区里。图标栏菜单里的“用户”项删除。

### 3.3 快捷键

- 所有全局快捷键（含 `⌥⌘Space` 快记）登记在 `src/shared/app-shortcuts.ts` 一张表里。
- 冲突的处理：`⌘,` 一律是全局设置；`⌘\` 一律是主题；日历的上下文栏开关换键并更新帮助。
- 新增 `scripts/check-shortcut-conflicts.cjs`：同一组合键在同一作用域登记两次即失败；模块内监听到表外的全局组合键即失败。

## 4. 技术约束

- **新代码放在 `src/renderer/modules/workbench/shell/`**（布局、图标栏、槽位、响应规则、命令注册表）。`WorkbenchMode.tsx` 只减不增：它离 1000 行的线很近，`useWorkspace.ts` 已在危险名单。
- **原生网页层。** 侧栏宽度、助手宽度、抽屉出现都改变网页区域：沿用 `useBrowserViewBounds` 的同步；任何浮在网页上方的 DOM 先隐藏网页层，消失后恢复并同步位置。每一步用真实窗口脚本验证让位与恢复。
- **保活与分屏。** 模式面板的保活、双模式分屏、模式过渡（`modules/workbench/mode-*.ts`）不改语义。导航器随模式挂载和卸载时不得丢失各自的滚动位置与展开状态（各模块已有会话状态，继续用）。
- **保留** Renderer 启动的白屏兜底与 `/workbench` 路由回退。
- **助手的工作面事实不变。** `workbenchMode` 仍然只有四个值；浏览器激活仍只读可信的结构事实（运行时合同 §6）。外壳改动不得改变 Main 冻结工具面时读到的当前工作面。
- 浏览器竖向标签栏的悬浮展开窗口（`VerticalRailOverlayWindow`、`vertical-rail-overlay-window.ts`）在标签进入外壳侧栏后不再需要，随 T3 删除；删除前确认标签拖拽、拖出为资源等行为在新列表里都有。

## 6. 合同 S1–S8

| 合同 | 标准 |
| --- | --- |
| S1 一个侧栏 | 任一模式、任一时刻，页面上带 `data-shell-sidebar` 的节点恰好一个，模式面板内部没有第二个导航侧栏容器 |
| S2 模式切换在图标栏 | 助手面板的 DOM 里没有模式切换控件；助手收起时仍能切换模式 |

| S5 入口唯一 | 下列各只有一个主入口：模式切换、对象搜索、反链、新建页面、打开日历、打开设置。脚本按可访问名称计数 |
| S6 设置诚实 | 设置页每个开关改动后重启读回一致；没有写死的示例数据 |
