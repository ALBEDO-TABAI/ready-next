# A0.5 — Source-Grep Cleanup Implementation Plan

> Status: planned-only. A0 writes this plan but does not execute it.
> Gate: A1 may start only after the agent / skill / runtime source-grep baseline is zero.

## Scope

A0.5 removes the grandfathered source-grep tests introduced into `eslint-rules/baseline.json`.

Two layers are intentionally separate:

1. **A1 hard gate:** source-grep entries under agent / skill / runtime ownership must be removed.
   - `src/__tests__/*agent*`
   - `src/__tests__/*skill*`
   - `src/__tests__/*tool*`
   - tests whose source target is under `src/main/modules/agent-control/`
   - tests whose source target is under `src/main/modules/skills-runtime/`
   - tests whose source target is under `src/main/modules/tools/`
   - tests whose source target is under `src/shared/` only when the shared file is consumed by agent / skill / runtime
2. **Non-blocking historical debt:** UI / style / visual contract source-grep entries do not block A1, but their baseline count must not increase.

## Execution Order

1. Snapshot the current baseline.
   - Run: `node scripts/check-eslint-baseline.cjs`
   - Record per-rule and per-area counts in this plan before editing.
2. Classify every baseline entry into `agent-skill-runtime` or `ui-style-history`.
   - Do not classify by filename alone when the test reads a target path; classify by the target source module when visible.
3. Rewrite agent / skill / runtime source-grep tests into behavior tests.
   - Prefer importing public functions and asserting real outputs.
   - If the production path depends on Electron, inject a fake host/runtime instead of reading source text.
   - Do not replace source-grep with snapshot-string tests.
4. Regenerate baseline after each small batch.
   - Run: `node scripts/check-eslint-baseline.cjs --update`
   - Run: `node scripts/check-eslint-baseline.cjs`
   - Baseline entry count must only decrease.
5. Stop when agent / skill / runtime baseline count is zero.
   - UI / style entries may remain, but `verify:a0` must still prove no new entries were added.

## Acceptance

- `node scripts/check-eslint-baseline.cjs` passes.
- `npm run lint:check` passes with 0 errors.
- Agent / skill / runtime baseline count is 0.
- UI / style baseline count is less than or equal to the A0 count.
- Every rewritten test has at least one behavioral assertion against runtime output, reducer output, gateway result, or repository state.
- No A1 / SubAgent implementation starts in this branch.

## Non-Goals

- Do not perform broad UI source-grep cleanup in A0.5 unless it is needed to keep the baseline from increasing.
- Do not weaken `ready/no-source-grep-test`.
- Do not add inline ESLint disables for source-grep tests.
