# 模型接入模块拆分

状态：已完成；验收见 `../audits/2026-09-26-model-gateway-modularization-validation.md`。基线提交：`c16d5e13`。

## 范围与不变量

按现有职责移动代码：HTTP 生命周期与转发、请求准入、原生事件校验、流式交付、供应商错误脱敏、Chat 请求与响应转换、数据库记录及凭据读取。保留现有单一网关、工具准入/交付顺序、重试边界、失败分类、快照摘要、历史协议和公开调用入口。不得引入调度器、兼容分支或新的持久状态。

## 先行可执行合同

- 新增 `codex-gateway-module-boundaries.test.ts`，要求网关入口不再包含协议状态机；协议/流模块不反向依赖 HTTP 服务或数据库；运行时依赖图无环；每个相关模块小于 1000 行。
- 原有供应商、恶意输入、流生命周期、凭据脱敏、停止、同轮工具准入及会话回归继续调用真实 `CodexModelGateway` 入口，不因拆文件改低验收标准。
- 移动期间逐个核对函数/类的语法树，确认实现体未丢失或改写；新增导出和 import 路径不算业务行为变化。
- 真实供应商候选摘要必须覆盖拆出的源文件，防止只修改子模块却继续使用旧候选摘要。

## 验收

1. 拆分前行为基线；拆分后同组测试、类型检查和构建。
2. `verify:native`、固定 app-server 网关/工具/压缩测试和运行时资产检查；运行时 manifest 与连续性资产保持字节不变。
3. 隔离真实 Electron 中的 GLM 5.3、Flash、Opus 5-5 读文档工具往返与续聊；不修改用户安装应用或原配置。
4. 更新当前架构入口与大文件台账，单独提交本轮整理；保留无关 Widget 改动。
