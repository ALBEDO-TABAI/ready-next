# Stage Y0.5 — Product dogfood matrix v3 sub-plan index

> Per parent plan §9.3, every Y0.5 surface gets a per-surface implementation
> sub-plan that scaffolds reproduction steps, expected results, pre-existing
> automated coverage, operator class, and acceptance. This INDEX file is the
> authoritative cross-reference. Baseline agents pick up one row at a time;
> the evidence files at `audits/2026-05-23-stage-y-closeout/dogfood/<slug>.md`
> are produced at baseline-execution time, NOT in this Y0.5 sub-plan phase.

## Operator-class legend

- `agent-only` — agent produces baseline evidence on CI-class hardware; no
  mandatory 白 spot-check (status=pass signable by agent alone).
- `agent-with-bai-spotcheck` — agent produces baseline; 白 MUST observe the
  surface at least once before status=pass is signed per §9.4. The
  `bai_spotcheck` frontmatter block is required per §9.2.
- `bai-only` — only 白 (or named release-engineer on W3.3 hardware) can
  produce signed evidence; agent baseline is preliminary.

## Cross-reference to evidence schema (§9.2)

Each sub-plan §5 names the evidence file at
`audits/2026-05-23-stage-y-closeout/dogfood/<surface-slug>.md` and the
matching `evidence/<surface-slug>-manifest.json`. None of those evidence
files exist at Y0.5 sub-plan time — they are created at baseline-execution
time per surface. See §9.2.1 for the capture-HEAD rule that ties every
evidence artifact to a clean working tree at capture time.
