# 动效语言

用户的要求（2026-11-24）：把整个项目的动效做到苹果那种细腻、丝滑的水准。不按部件列清单，而是按“状态变化”去找：出现、消失、移动、变大小、换内容、换图标、数值跳动、按下、悬停、加载、完成、出错，每一处都问一句：用户看得懂吗？是突然跳过去的，还是有来有去、交代清楚了？

标准：

- 动效用来解释发生了什么：东西从哪来、到哪去、和什么有关，不是装饰。
- 全项目一套语言：同一类变化用同一种曲线和节奏。
- 克制：快、轻、不抢戏；反复做的操作更快，宁可少动也不乱动。
- 跟手、可打断：拖动和调整大小时直接跟手，动画进行中再次操作也能自然接上。
- 不付性能代价：只动必要的属性，长内容里也要稳定满帧，量过再交付。
- 不引入新问题：不抖、不闪、不重排、不溢出，尊重系统的“减少动态效果”。
- 手机宽度、窄窗口、宽屏、深浅色都成立。

本文是这次改动的合同，取代 vvf 设计语言 V9 一行里“120 / 200 / 320ms、一条曲线”的简写（V9 的按压回弹保留）。先合同，后代码；每条规则都对应一个检查。

## 1. 令牌（M1）

令牌只在 `src/renderer/design/next/tokens.css` 定义。

| 令牌 | 值 | 用在哪里 |
| --- | --- | --- |
| `--rn-d-1` | 120ms | 悬停、按下、焦点等反馈；原地的小变化（图标替换、勾选）；浮层和小元素的离开 |
| `--rn-d-2` | 200ms | 浮层、对话框、提示条的出现；内容替换；开关；选中指示的移动；列表项进出；模式切换 |
| `--rn-d-3` | 320ms | 面板的展开和收起、较大距离的位移 |
| `--rn-d-4` / `--rn-d-5` | 480 / 640ms | 只给一次性的编排（翻书、主题切换仪式、启动画面），不用于日常操作 |
| `--rn-d-release` | 520ms | 按下后松开的回弹（V9），只配 `--rn-ease-spring` |
| `--rn-d-spin` / `--rn-d-loop` / `--rn-d-flash` | 1s / 1.6s / 1.2s | 转圈一周（和光标闪烁）；“还在进行”的呼吸、扫光、进度条；跳转后“就是这里”的一次高亮 |
| `--rn-ease-out` | `cubic-bezier(.22, 1, .36, 1)` | 到达：出现、移到新位置后停下 |
| `--rn-ease-in` | `cubic-bezier(.32, 0, .67, 0)` | 离开：移出视野、行程 ≥200ms 的东西加速离开；120ms 的淡出一律用 std（ease-in 会让旧画面停留过久，和新画面叠在一起） |
| `--rn-ease-std` | `cubic-bezier(.2, .8, .2, 1)` | 原地变化：颜色、透明度、可来回切换的状态 |
| `--rn-ease-in-out` | `cubic-bezier(.65, 0, .35, 1)` | 两端都在屏幕上的长距离移动 |
| `--rn-ease-spring` | 支持 `linear()` 时是 vvf 弹簧曲线 | 按下松开的回弹、开关滑块落位 |
| `--rn-ease-liquid` / `--rn-ease-shelf` | 不变 | 只在液态玻璃和书架模块内部 |
| `--rn-shift-1` | 4px | 浮层从锚点方向出现的位移 |
| `--rn-shift-2` | 8px | 提示条、列表项、内容块出现的位移 |
| `--rn-shift-3` | 24px | 模式场景、侧栏导航进出的位移 |
| `--rn-pop` | .97 | 对话框出现时的起始缩放 |

“减少动态效果”打开时，位移令牌为 0、`--rn-pop` 为 1、弹簧曲线退回 `--rn-ease-std`：用这些令牌的动画都只剩淡入淡出，时长不变。所以“减少动态效果”下变化仍然交代清楚，只是不再移动。

## 2. 每类变化怎么动（M2）

| 变化 | 进入 | 离开 | 属性 |
| --- | --- | --- | --- |
| 悬停、焦点 | `d-1` std | 同 | 颜色、背景、透明度 |
| 按下（按钮、图标按钮） | 110ms out 缩到 .94 | 松开 `d-release` spring 回弹 | transform |
| 菜单、下拉列表、弹出面板、悬停提示 | `d-2` out，淡入并从锚点方向移 `shift-1` | `d-1` std 原地淡出 | opacity、transform |
| 对话框 | `d-2` out，淡入并从 `pop` 放大；遮罩淡入 | `d-1` std 淡出 | opacity、transform |
| 提示条（toast） | `d-2` out，淡入并上移 `shift-2` | `d-1` std 淡出；新的一条替换旧的一条时交叉淡化 | opacity、transform |
| 模式切换 | `d-2` out，沿图标栏的方向（竖直）移 `shift-3` 并淡入；内容区和侧栏导航同一个轴 | `d-1` std，向另一侧移半个 `shift-3` 并淡出（比进入快） | opacity、transform |
| 侧栏、助手面板展开收起 | `d-2` out，两个方向同一时长（⌘B 和助手开关最常按）；面板里的内容保持展开时的宽度，随边缘滑入滑出 | 同 | 列宽（M4 白名单），内容不重排 |
| 抽屉、浮动侧板 | `d-2` out，从自己那一侧移 `shift-2` | `d-1` std 淡出 | opacity、transform |
| 内容替换（文字、图标、状态标签） | 交叉淡化 `d-1`～`d-2` std | 同 | opacity |
| 数值变化 | 等宽数字，位数变化不挤动邻居 | | 不做滚动计数 |
| 列表项进出 | `d-2` out 淡入并移 `shift-2` | `d-1` std 淡出 | opacity、transform |
| 选中指示移动 | 唯一的弹簧 `SPRING_UI`（约 250ms，bounce .1） | | transform |
| 加载 | 转圈 `d-spin`；骨架用透明度呼吸 `d-loop`（不扫渐变）；网页加载条只向前，不倒退 | 完成时淡出 | opacity、transform |
| 完成 | 对勾从 .7 弹簧放大出现（`.rn-glyph-in`）；只在屏幕上发生变化时动，打开一份已经完成的列表不动 | | opacity、transform |
| 出错 | 颜色 `d-1` std；不抖动 | | 颜色 |
| 拖动、调整大小 | 拖动中不加过渡，直接跟手 | 松手后 `d-2` out 落位；面板动画结束后正文栏的位置变化也用 `d-2` 滑到位，不跳 | transform |
| 悬停时出现的控件 | 显示 `d-1`，隐藏延迟一拍再 `d-2` 淡出（块把手） | | opacity |
| 按钮上的状态文字 | 宽度按最宽的文字预留（`StableLabel`），保存 → 正在保存… 不挤动旁边 | | |

## 3. 可打断（M3）

- 能来回切换的状态（展开/收起、选中、悬停、模式场景）用 transition，不用 keyframes：动画中途反向时从当前值接着走，不跳回起点。
- keyframes 只用于挂载时的一次性进入和无限循环的加载指示。
- 离开的元素（浮层、提示条）不阻塞交互：离开时立刻不接收指针，焦点已经还给原处。

## 4. 性能（M4）

- 只动 transform 和 opacity；颜色、背景只在小元素上过渡。
- 不对宽高、上下左右、边距做过渡，不对大面积的 filter、backdrop-filter、box-shadow 做动画。确需改变尺寸的（面板宽度）在白名单里写明原因，拖动中关闭过渡。
- 无限循环的动画在看不见时停下（隐藏的模式场景、挂起的面板）。
- `will-change` 只放在正在动或马上要动的元素上。

## 5. 减少动态效果（M5）

- 位移和缩放令牌在系统“减少动态效果”下归零（M1），所以用令牌的动画自动变成淡入淡出。
- framer-motion 在应用根部用 `MotionConfig reducedMotion="user"`，变换类动画跟随系统设置。
- 原有各文件里的 `prefers-reduced-motion` 规则保留。

## 6. 检查（M6）

- `scripts/check-motion.cjs`（接入 `npm run verify:design-tokens`）：
  - Renderer 的 CSS 里，transition 和 animation 声明的时长和曲线只用令牌（`0s`/`0ms`、无限旋转的 `linear`、`steps()` 除外），例外写进 `scripts/check-motion-allowlist.json` 并注明原因；
  - 不对布局属性（宽高、上下左右、边距、inset）做 transition，例外同上；
  - 不用 `transition: all`；
  - TSX 里的 Tailwind 动效类不写裸时长（`duration-150` 之类），用令牌（`duration-(--rn-d-1)`）。
- 单元测试覆盖浮层的离开副本（不接收指针、不带 id、结束后移除）和提示条替换。
- 隐藏窗口帧测：模式切换、打开菜单、长文档滚动、资讯长列表滚动，记录帧间隔 p50/p95 和超过 33ms 的帧数。
- 设计矩阵截图（浅色、深色，宽窗口、窄窗口）确认没有溢出、错位。

## 7. 改动清单（按状态变化）

顾问子 agent 的审查报告（41 项，P0–P2，含文案与交互）和自己的审查合并后实施。路径相对 `src/renderer/`。

**出现与消失**
- 菜单、下拉、弹出面板、悬停提示、对话框（`components/ui/float/Float.tsx`、`primitives.css`）：原来直接弹出、直接消失。现在从锚点方向出现；关闭时元素立刻移除（焦点归还、不挡指针），一个不可交互、无 id 的副本在原处淡出（`components/ui/leave.ts`）。在网页上方出现时，入场动画在网页让开、浮层真正可见时才开始。
- 不走统一浮层的 11 处：块编辑器的斜杠菜单、命令菜单、文字格式条、日期选择、新建子页面，文档选区工具条，输入框上方的模型、@、斜杠、授权、项目菜单（`FloatPanel` 统一加 `motion`，向上打开的标 `up`），上下文用量提示，快速预览，关系图谱悬停预览，资讯设置抽屉，网页加载条：都有了同样的出现和淡出。
- 提示条（`Toast.tsx`、`toast-store.ts`）：新的一条替换旧的一条时交叉淡化；悬停或获得焦点时计时暂停；带操作按钮的至少停留 6 秒。
- 悬停提示连续经过工具栏时，600ms 内下一个立即出现。
- 模式首次加载的占位文字在 300ms 后才淡入，并统一为“正在加载…”。

**移动**
- 模式切换（`components/layout/WorkbenchModeOutlet.tsx`、`modules/workbench/scene-motion.ts`、`styles/ritual-overlay.css`、`modules/workbench/shell/*`）：原来是关键帧，快速连点时场景会跳回起点、离开的场景中途消失，横移 28% 面板宽。现在是 transition + `@starting-style`，内容区和侧栏导航沿同一竖直轴移动 24px；每个离开的场景各自计时，中途折返从当前位置接着走。
- 浏览器 Agent 的指针（`pages/BrowserAgentPointerWindow.tsx`）：原来每次动作重建元素，实际是跳过去的，标签和圆圈还分开动。现在整体用一个 transform 滑到下一处，按下时圆圈收紧。
- 侧栏、助手面板开合：统一 `d-2`；助手内容保持展开宽度、随边缘滑入（不再逐帧重排对话和重建输入框玻璃）；面板动画后正文栏的位置变化改为平滑归位（原来最后一帧跳 64px，`modules/document/documentLayoutFreeze.ts`）。
- 抽屉的位移统一为 `shift-2`（原来 8 / 12 / 12 / 18px 四种）。

**按下、悬停**
- 图标栏按钮原来有三种按下手感（framer 的 .992 下沉、-0.4px 悬停上浮、没有反馈），且 CSS transition 和 framer 抢同一个 transform。现在全部是 V9 的 .94 + 释放弹簧。
- 资讯列表和筛子里局部的 transition 覆盖掉了按钮的回弹，已补上；门禁新增 `css-press` 防止再犯。
- 选中胶囊的弹簧原来过冲约 15%，现在统一 `SPRING_UI`。
- 菜单项、标签、行的悬停颜色从“瞬间变色”改为 `d-1` 渐变；块把手显示快、隐藏慢，鼠标扫过页面不再一路闪。

**换内容、换图标、数值**
- 发送 / 停止（`components/agent/ChatInput.tsx`）：原来是两个按钮硬切，还会变成红色。现在是同一个墨色按钮，箭头、方块、转圈交叉淡化。
- 复制后的对勾、任务步骤完成的勾：弹簧放大出现；复制反馈统一停留 1.5 秒。
- 上下文用量圆环：长度和颜色 `d-3` 过渡，不再跳变。
- 工具步骤完成时的闪烁：运行中的扫光改为透明填充而非透明颜色，完成时只有颜色从 ink-2 过渡到 ink-3。
- 收集数量角标：弹出出现，数字等宽。

**加载、完成**
- 网页加载条原来每 1.5 秒从头再来，看起来像倒退；现在只向前，越来越慢地停在九成，加载完淡出。
- 骨架屏改为透明度呼吸（不再逐帧重绘渐变）；所有“还在进行”的循环统一为 `d-loop`。

**文案（状态变化里的文字）**
- 数据库状态：“已合入未保存缓冲” → “有改动待保存”，“冲突” → “有冲突”。
- 保存、测试、刷新按钮：状态文字统一为“正在保存…”“正在测试…”“正在刷新…”，按钮宽度不随文字变化（`components/ui/StableLabel.tsx`）。
- 省略号统一为“…”。

**性能**
- 输入框玻璃下面的对话副本不再重复运行对话里的动画（`styles/liquid-composer.css`）。
- 网页上方的菜单和对话框：网页让开前先截一张静帧垫在原处（两个窗格同时请求时共用一次截图，图片解码并画上后网页才让开；遮罩期间调整窗口大小也不撤掉静帧），菜单打开期间网页不再变成空白；资讯的原文预览同样处理（`modules/overlay/browserViewMask.ts`、`modules/browser/useBrowserResizeFreeze.ts`、`modules/overlay/useOverlayPageStill.ts`）。浮层的淡出副本不占住网页：关掉建议列表后可以立刻点网页。

**减少动态效果**
- 距离令牌归零，所有用令牌的动画自动变成淡入淡出；framer-motion 跟随系统设置；12 处平滑滚动改走 `scrollBehavior()`；补上宠物、书架标签、书房阅读器的规则；按下不再缩放。

**统一**
- 约 270 处写死的时长和曲线改为令牌；Tailwind 的 `transition-*`、`ease-*`、`animate-spin/pulse` 映射到令牌；脚本侧用 `design/next/motion.ts`（测试保证与 `tokens.css` 一致）。剩下的 87 处在 `scripts/check-motion-allowlist.json`，每条写明原因（主题切换仪式、书房书架编排、滚动驱动动画、面板宽度）。

  单次模式切换的偶发长帧（首次挂载场景）新旧版都有，量级相同。
