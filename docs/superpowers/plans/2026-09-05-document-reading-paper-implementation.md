# 阅读模式纸张、落页与开销修复

## 范围与完成合同

沿用现行只读 DOM 书页，不引入截屏、WebGL、第二套分页或正文写入。

1. 纸张为等宽、不可拉伸的连续曲面；两端精确共面，曲率及透光随起落连续归零。正反面身份、文字方向与静态页边距保持一致。
2. 松手收束不可穿过平放终点再回弹；最后一帧先精确落平，再同步交接静态页。反向、取消、失焦、暂停帧、重复输入都不可重置活动页身份。
3. 左右纸堆厚度随已读/未读页数互补变化，薄书与厚书有区别；切口纹理沿页高竖向延伸，禁止横向栅格。前页与纸堆上下齐边，圆角只留在最外侧，四角不凸出。不能在翻页结束后再补一次布局动画。
4. 背景默认随应用昼夜模式变化，也可选自定义颜色并保存；配色不触发全文重新分页或移动阅读位置。
5. 逐帧操作不能引发嵌套切片后代反复计算；预热只在空闲进行、可取消，隐藏/卸载无挂起工作。静态正文选择、链接、重排与位置保存保持有效。

## 验证

- 数学和控制器行为测试：连续曲面、端点、时间步长、落页顺序、纸堆守恒。
- 真实组件测试：透印身份、克隆上限、预热竞态、配色存取、取消和重排。
- 同一长文/尺寸/运行时在 Electron 中测量修复前后翻页帧时、绘制/布局开销与闲置状态。
- `verify:document-reading`、`typecheck`、CSS 层检查；偏好持久化跑 `verify:native`。
- 新包通过签名与包体核对，安装后在真实 Ready 阅读窗口验收。

## 已发现根因

- 展开状态左纸堆强制为 0；厚度仅由封面外延计算，与书长无关。
- 叶片没有实际透印内容层；背面遮光端点残留 0.025，投向对侧的阴影终点仍达峰值。
- 弹簧显式积分允许越过 π；曲面和阴影分别钳制后又随回弹重新抬起。
- K 层切片嵌套，逐片写入继承变量导致后续切片和内容重复样式计算。空闲回调不取消，也未阻止翻页中改装为下一张页。
